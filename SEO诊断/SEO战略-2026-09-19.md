# Palworld SEO 战略约束（2026-09-19 定稿）

> 性质：本文件是 Palworld 站后续一切判断的**最高约束**，与《SEO施工表-2026-09-19.md》配套（战略=为什么，施工表=做什么）。
> 定稿背景：2026-09-19 用户拍板——把"做出竞争对手没有的功能"的权重清零，全面转回 SEO Coverage Gap 打法。此前方向偏差（My Pals / Acquisition Planner / Catch vs Breed 算法 / Progression Engine / World Tree Planner）一律作废。

## 一、目标（唯一口径）

> **用最低的开发成本，持续获得更多 Google 自然搜索曝光和点击，并在目标 Query 上超过当前竞争页面。**

不做"最好用的 Palworld 工具站"。功能只有在**直接帮助 SEO 排名、CTR、覆盖更多搜索意图或建立内链**时才做，否则哪怕功能很好也不做。

## 二、SEO 优先级（五条，按顺序，不可跳级）

**第一：有没有真实搜索需求。**
来源只看（按优先级）：GSC Query → Google Suggest / 相关搜索 → 当前 SERP → Reddit / Steam 等真实玩家问题 → 竞争页面覆盖。没有搜索需求证据，不开发。

**第二：我们现在有没有机会排名。**
优先顺序：Position 4–10 → 11–20 → 21–50 → 已获得 Impression 的新 Query → SERP 存在明显内容缺口的新关键词。不因"功能很好"就开发。

**第三：目标 Query 的页面能不能比 Top SERP 更好。**
"更好"≠功能更多，而是：**对目标搜索词回答得更直接、更完整、更准确、更新、更容易被 Google 理解。**

**第四：一个页面尽可能吃掉同一 Intent Cluster。**
不是 1 词 = 1 页。意图一致的 Query 集中在同一个 URL（例：`astegon location` / `where to find astegon` / `astegon coordinates` / `astegon spawn` / `astegon boss location` 全部归 `/pal/astegon/location`），把一个 URL 做强，而不是把权重拆掉。

**第五：程序化页面只做 Google 已经验证的模板。**
已验证：Location。可继续实验→成功→扩大。
Breeding / Item / Pal Detail：先看各自 GSC 是否产生足够信号，再决定扩什么内容。不因"理论上能做"就开发。

## 三、超竞争方法 = SEO Coverage Gap（不是 Feature Gap）

每个重点 Query 固定执行管线：

```text
TARGET QUERY → Top10 SERP → Search Intent → 共同覆盖内容 → 竞争页缺失内容
→ Google PAA / Suggest / Related Searches → Reddit / Steam 真实问题 → 我们的 GSC Query
→ 形成 Content Brief → 修改页面
```

页面终态两条标准：
1. **Top 10 普遍回答的问题，我们不能缺。**
2. **Top 10 普遍没有回答、但真实用户正在搜索的问题，我们优先补。**

## 四、开发项准入测试（一票否决）

每个开发项必须能明确回答：**"这个修改具体是在抢哪个关键词？"**

回答不了 → 直接删除。不再因为看到竞争对手有复杂工具，就把我们带到产品功能竞争上。
