## 二、Location 簇（astegon 旗舰）

### Suggest
`astegon entrance`(×3) / `astegon saddle` / `astegon weakness` / `astegon breeding combos` / `astegon location 1.0`(×3) / `astegon location map` / `astegon location and level` / `where to find astegon boss palworld`。**"1.0"版本后缀在 3 个 seed 全部出现；我们 0 曝光在 entrance/map/1.0 类词。**

### Top10 普遍覆盖 vs 我们
- 双地点（Destroyed Mineshaft 洞窟 + No.3 Wildlife Sanctuary）
- 明写 fast travel 起点名（Mount Obsidian Midpoint / Deep Sand Dunes）
- 多源坐标不一致被标出（我们只给 top5 单一值→其他站读者会怀疑我们错）
- 1.0 改版说明（哪些点作废、alpha 移到 No.2 保息区）
- 掉落+捕捉门槛（Hyper Sphere 起）+弱点 Ice
- "最速路线"标签、reroll 刷怪法、夜行性
- **"Astegon does not spawn in dungeons" 排除项**
- 重生计时 ~1 游戏日

### Title 公式（40+ 标题统计）
统治级两条：① Game8 式 `{Pal} Location, How to Breed, and Drops | Palworld` ② Exputer 式 `Palworld {Pal}: Location, Fight, Stats [Quickest Method]`。**没有任何 Top 结果是光秃秃的 `{Pal} Location – Palworld`**——这是我们 0/363 点击的最可能主因。

### Not Spawning 真实困惑与答案
1. 地图 boss 图标是区域标记非精确点，boss 在地下洞窟（崖壁暗色横向隧道口、岩浆面、火把标记）——"图标不在洞口正上方"不是 bug
2. 三别名混用（Destroyed/Abandoned/Scorching Mineshaft=同一处）
3. Alpha 重生 ~1 小时
4. No.3 保息区只有普通稀有刷新，无 alpha 变体——蹲不到 alpha 是预期错误
5. 1.0 版本分支：Game8 称 alpha 移去 No.2(-689,-115)；pindrop.gg 游戏文件称 Palpagos 野生点归零只剩 World Tree 21 点——**站点必须给版本分支而非单一答案**（当前 SERP 最大信息不一致）

### 抽查词 title（anubis coordinates / foxcicle boss / kingpaca cryst）
5/5 全部"主词+第二价值点"公式；弱 Pal 用绰号替代（Frostbound Fox）。

### Astralym 繁殖正确答案
**不能繁殖。** 最终 Boss/Sealed Sanctum/不可捕捉/无任何组合/无蛋。计算器站 Astralym+Astralym=Astralym 是数据挖掘残留。Lore：官方日志 "lacks the necessary biology"。唯一获取=Mod。**英文 query 命中我们 zh-CN 页(pos 8.9)=语言错配天花板**，同模式 zh-TW jormuntide-ignis 被压 pos 57。英文端该主题只有一篇新闻稿吃=结构性空位。
同种配特例名单：Jetragon/Frostallion/Paladius/Necromus/Jormuntide Ignis/Bellanoir Libero/Xenolord/Neptilius/Hartalis。
Jormuntide Ignis 正确组合=Jormuntide+Blazehowl（樱岛更新唯一独特组合）。

## 四、全局发现
1. Game8 碎片化=最大护城河（每技能单页）；pindrop.gg/paldb.cc/op.gg 等数据站有繁殖计算器+分布图工具化能力——我们不拼工具，拼 Coverage Gap。
2. 多语言竞品已进英文 SERP（games.gg zh 页、playground.ru、jeuxvideo.com）——语言不匹配仍可排名，但同语言竞品一旦补位我们中文页会被挤。
3. 计算器 datamined 残留是内容机会（"计算器说 X，游戏里其实不能"类页面有信任红利）。
4. 掉率口径有分歧（10% 首通 vs 可复刷）——写内容标版本，不直接抄。
5. `astralyn zzz` 是 ZZZ 跨游戏噪声，词表排除。
