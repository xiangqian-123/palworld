## P0-1 Location 三页 title/description 重写（CTR 冲刺，最高 ROI）

**抢的词**（GSC 证据）：`astegon location`(41imp pos 8.6) / `astegon location palworld`(22) / `astegon palworld location`(36) / `palworld astegon location`(16) / `astegon palworld location map`(3) / `astegon not spawning`(1, pos 9)；jormuntide / neptilius 同构词系。三页合计 363 曝光 **0 点击**——同 SERP 竞品标题全部是"主词 + 2-3 个价值点"，我们是光秃秃的 `Where to Find X — Spawn Location`，这是 0 点击最可能主因。

**改什么**：
1. `app/[locale]/pal/[slug]/location/page.tsx:42` 的 title 模板不动（288 页实验期），在 generateMetadata 加 per-slug 覆盖表（先 3 个 slug，成功后再考虑推广模板）：
   - astegon（有 not spawning + map 细分需求，用宽钩子公式）：
     `Where to Find Astegon in Palworld – All Spawn Locations, Coordinates & Not Spawning Fix`
   - jormuntide / neptilius（意图宽，用 Game8 对标公式）：
     `Jormuntide Location, Spawn Map & How to Get | Palworld 1.0`
     `Neptilius Location, Spawn Map & How to Get | Palworld 1.0`
2. description 同步加第二价值点（当前 description 已含等级+昼夜，补：alpha 坐标点数量、breeding 备选、1.0 版本标注）。
3. 注意：title 提到 "Spawn Map" 前，页面需先有地图元素（见 P1-2 地图实验）或降级用 `All Spawn Locations & Coordinates`——**如果 P1-2 不做，title 里不许写 Map**（禁止承诺页面没有的东西）。

**数据素材**：无（纯文案）。公式依据：2026-09-19 SERP 研究（Game8 式 `{Pal} Location, How to Breed, and Drops | Palworld` 统治该 SERP；"最速"式 `[Quickest Method]` 方括号钩子次之）。

**完成标准**：3 个 URL 线上 title 含第二价值点；GSC 观察项（不阻塞）：7 天后 3 页合计 clicks ≥ 1，14 天 CTR ≥ 1%。
