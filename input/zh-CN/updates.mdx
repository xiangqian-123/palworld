Palworld 自 2024 年 1 月 19 日抢先体验上线以来持续更新。2026 年 7 月 10 日正式发布 1.0 版本，告别 EA 阶段。本页汇总全部版本历史。

## 1.0 正式版核心内容

1.0 是 Palworld 迄今最大的更新：

| 内容 | 说明 |
|------|------|
| Pal 总数 | 全游戏共 **287 种 Pal**（官方维基百科数据） |
| World Tree 世界树 | 主线终章，终于可进入（8 座塔封印剧情） |
| Pal 觉醒/突变 | 强化 Pal 或培育突变个体（变异蛋） |
| 200+ 伙伴技能重做 | Partner Skills 大幅改进 |
| 新材料 | Hardwood、Soralite、Paloxite、World Tree Holy Water 等 |
| 等级上限 80 | 从 EA 阶段提升 |
| 多人改进 | 跨平台联机、语音聊天、公会权限、服务器工具 |

## 重大更新详解

### v0.5.0 — 跨平台联机（2025-03-19）
首次支持 PC / PS5 / Xbox / Mac 跨平台联机。房主在 World Settings 开启 Cross-Play。

### v0.6.0 — Tides of Terraria（2025-06-25）
与 Terraria 联动，新增 27 Pal、3 岛屿、Terraria 地下城、钓鱼/打捞系统、Arena 竞技场。详见[Terraria 联动攻略](/zh-CN/guide/terraria)。

### 1.0.0 — 正式版（2026-07-10）
最大更新。在 Summer Game Fest 2026 公布。开放 World Tree 世界树主线终章、Pal 觉醒/突变系统、总计 287 种 Pal。Steam 限时 25% off 庆祝。

## Nintendo 专利纠纷

Palworld 与 Nintendo（任天堂）及 The Pokémon Company 的诉讼是近年游戏圈最大争议之一。完整时间线：

| 时间 | 事件 |
|------|------|
| 2024-01-24 | The Pokémon Company 发声明，称收到大量关于"另一家公司 1 月发售游戏"的问询，将"调查并采取适当措施" |
| 2024-09-18 | **Nintendo + The Pokémon Company 正式向东京地方法院起诉 Pocketpair**，指控侵犯专利权（帕鲁球捕捉机制类似宝可梦的捕捉机制） |
| 2024-09 | 索赔额：**两家各 500 万日元** + 迟延损害赔偿，并要求禁令阻止 Palworld 发售 |
| 2024-11 | Pocketpair 回应"不知晓侵犯了任何专利"，并发布补丁修改了与宝可梦相似的机制 |
| 2024-12 | Nintendo 在美国提交 23 项专利，最终 **1 项获批、其余被驳回** |
| 2025 | Pocketpair 抗辩：Dark Souls III 的 Pocket Souls Mod 等先例使任天堂专利无效；任天堂称"Mod 不算独立游戏、不构成专利侵权" |
| 2026-10-01 | 法院安排**证据陈述** |
| 2026-11-09 | 法院将**发表意见** |

> 因诉讼影响，Palworld 上 Nintendo Switch 的可能性极低；目前也暂无 PS4 版本。
