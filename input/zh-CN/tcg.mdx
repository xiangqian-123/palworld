## 卡牌类型

Palworld TCG 有 5 种卡牌类型：

| 类型 | 说明 |
|------|------|
| Pals 帕鲁 | 核心战斗单位，有攻击力和体力 |
| Gears 装备 | 装备给 Pal，增强能力 |
| Structures 建筑 | 放置在基地区，提供功能 |
| Events 事件 | 即时效果卡 |
| Souls 灵魂 | 部署 Pal/装备/建筑的资源 |

## 玩法概要

- 牌组：50 张
- 目标：将对手 Life Counter 从 10 降至 0
- 每回合抽 2 个 Soul（上限 10）
- 用 Soul 部署卡牌到 Base 基地区
- Pal 可以攻击对手 Pal / 建筑 / 或直接 Strike 玩家
- 力量值 Power 决定战斗胜负，生命值 HP 每回合重置
- Strike 数决定翻转牌数，Lucky Symbol 可免伤
