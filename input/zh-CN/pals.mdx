Palworld 1.0 正式版共有 287 种 Pal 幻兽，涵盖 9 大元素属性。本页是 Pal 图鉴导航，含分类索引和最佳推荐。

## Pal 属性分类

Palworld 的 Pal 分为以下元素属性：

| 属性 | 说明 | 代表 Pal |
|------|------|---------|
| Neutral 无属性 | 基础属性，无克制关系 | Cattiva、Lamball |
| Fire 火 | 克制 Grass/Ice | Foxparks、Blazehowl |
| Water 水 | 克制 Fire | Azurobe、Penking |
| Grass 草 | 克制 Ground | Lifmunk、Robinquill |
| Electric 电 | 克制 Water | Sparkit、Orserk |
| Ice 冰 | 克制 Dragon | Foxcicle、Frostallion |
| Ground 地 | 克制 Electric | Rushoar、Digtoise |
| Dark 暗 | 克制 Neutral | Daedream、Maraith |
| Dragon 龙 | 克制 Dark | Jetragon、Quivern |

## Pal 获取方式

| 方式 | 说明 |
|------|------|
| 野外捕获 | 用 Pal Sphere 帕鲁球 捕获野生 Pal |
| 养殖 | 在 Breeding Farm 养殖场配对获得 |
| BOSS 掉落 | 击败塔 BOSS / 突袭 BOSS |
| 任务奖励 | 完成特定任务获得 |
| 特殊位置 | 传说 Pal 固定刷新点 |

> Pal 没有**进化系统**。变体形态（如 Mossanda Lux、Jormuntide Ignis）是独立物种，需单独捕获或养殖。
