每个 Pal 最多拥有 0–4 个被动技能 Passive Skills，提供攻击、防御、工作速度、移动速度、理智等加成或负面效果。被动按稀有度分为 **Rank 4（彩虹阶，最强）→ Rank -3（最差）** 共 7 档。

## 被动分级（权威 Rank 体系）

### Rank 4（彩虹阶，最强）

| 被动 | 核心效果 |
|------|---------|
| Legend 传说 | +攻击 / +防御 / +移速（传说 Pal 专属） |
| Demon God 魔神 | +攻击 / +防御（0.4.11 新增） |
| Diamond Body 钻石之躯 | +防御 |
| Eternal Engine 永动机 | 耐力相关 |
| Vampiric 吸血鬼 | 吸血 |
| Invader 入侵者 | 攻击相关 |
| Swift 迅捷 | +移速（0.4.11 提升为彩虹阶） |
| Siren of the Void 虚空塞壬 | +30% 暗属性伤害 |
| Remarkable Craftsmanship 神匠 | **+75% 工作速度**（终极工人） |
| Lucky 幸运 | +工作速度 / +攻击 |
| King of the Waves 浪之王 | 水中坐骑加成 |
| Lunker / Ranch Master / Savior 等 | 钓鱼 / 牧场 / 生存 |

### Rank 3（强力）

Artisan 工匠、Burly Body 壮硕、Workaholic 工作狂、Serenity 宁静、Ferocious 凶猛、Runner 奔跑者、Noble 贵族、Philanthropist 慈善家、Motivational Leader 激励领袖、Stronghold Strategist 要塞战略家、Vanguard 先锋、无限耐力、以及元素强化系（见下）。

### Rank 2

Musclehead 蛮力（+攻击 / -工作速度，纯战斗）。

### Rank 1（普通/双刃）

Brave 勇敢、Serious 认真、Work Slave 工作奴、Impatient 急躁、Nimble 灵巧、Fine Furs 华贵毛皮、Insomnia 失眠 等数十种。

### 负面被动（Rank -1 ~ -3）

Clumsy 笨拙、Coward 懦弱、Slacker 偷懒、Pacifist 和平主义、Brittle 脆弱、Destructive 破坏、Glutton 暴食 等。

## 关键被动效果说明（易错点）

| 被动 | 正确效果 | 常见误传 |
|------|---------|---------|
| Serenity 宁静 | 主动技能冷却 -30% + 攻击 +10% | ❌ 误传为"理智恢复" |
| Philanthropist 慈善家 | 提升**配种速度**（养殖计时） | ❌ 误传为"牧场产蛋" |
| Remarkable Craftsmanship 神匠 | +75% 工作速度（彩虹阶） | ❌ 误传为"Golden Touch"（不存在） |
| Siren of the Void 虚空塞壬 | +30% 暗属性 | ❌ 误传为"Shadow Ruler"（不存在） |

| 被动 | 对应元素 |
|------|---------|
| Flame Emperor 炎帝 | Fire 火 |
| Ice Emperor 冰帝 | Ice 冰 |
| Earth Emperor 地帝 | Ground 地 |
| Lord of Lightning 雷之领主 | Electric 电 |
| Lord of the Sea 海之领主 | Water 水 |

## 最佳 4 被动组合（1.0 版本）

### 纯 DPS 战斗
```
Legend + Musclehead + Serenity + 30%元素被动
```
> 1.0 之后 Serenity（冷却 -30% + 攻击 +10%）已取代旧版 Ferocious/Brave 组合。

### 元素输出战斗
```
Legend + Musclehead + 30%元素被动 + Impatient
```

### 坦克 / 生存
```
Legend + Diamond Body + Burly Body + Stronghold Strategist
```

### 速度坐骑
```
Swift + Runner + Legend + 无限耐力/灵巧
```

### 终极基地工人
```
Artisan + Work Slave + Serious + Remarkable Craftsmanship
```
> 工作速度：基础 70 × 215%（被动）× 130%（强化）= 约 195。4 星浓缩后各工作适性 +1，每级适性比上一级快 3 倍（Lv1→Lv5 约 81 倍）。

## 被动继承规则

1. 合并双亲被动（去重）后，掷"继承数"（1–4，概率 40%/30%/20%/10%）
2. **双亲有相同被动对概率无帮助也无害**
3. 继承全部目标被动的概率：1 个 40%、2 个 24%、3 个 12%、4 个 10%
4. 最佳做法：双亲合计只留 4 个目标被动（2+2 / 3+1 / 4+0）
5. **Legend、元素 Emperor 不能随机突变**，必须从父母继承

详见[养殖攻略](/zh-CN/guide/breeding)。

## World Tree 世界树专属被动

World Tree 区域有独特的被动获取途径：
- 捕捉带蓝色光晕的野生 Pal
- 用 Ancient Relic Recycler 回收远古圣物换 Disposable Implants
- 孵化世界树中的 Ominous Egg

变异蛋会孵出带**变异专属被动**的 Pal：Babysitter、Heavily Armored、Idiosyncratic、Immortality、Skymarcher。

## Pal Surgery Table 修改被动

v0.6.0 引入的 Pal Surgery Table 帕鲁手术台 可以：
- 覆盖现有被动技能（花金币，部分被动需植入物）
- 改变 Pal 性别
- Serious / Nocturnal / Philanthropist / Workaholic 等关键被动可直接植入（无需先获得植入物）

> 所有平台可用（不仅 PC），这是官方内置功能。
