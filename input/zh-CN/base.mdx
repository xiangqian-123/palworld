基地是 Palworld 的核心，捕捉、生产、养殖、制作都围绕据点展开。一个规划得当的基地能全自动产出资源，规划差的基地则天天被突袭、Pal 罢工。本攻略从选址到自动化全流程讲解。

## 基地选址（最重要的一步）

基地位置决定资源获取效率，选址前先确认附近有什么：

| 考量 | 建议 |
|------|------|
| 地形 | 平坦开阔地，方便摆建筑 |
| 矿点 | 附近有 Ore 矿石 矿点（后期刚需） |
| 水源 | 靠近水源，方便浇灌 |
| 安全 | 避开高等级敌对 Pal 聚集区 |

> 提示：前期一个基地，后期可开多个基地分工——一个采矿、一个伐木、一个养殖，比单一「万能基地」效率高得多。

## Palbox 与基地半径

Palbox 帕鲁箱 是据点核心，2 级解锁，可容纳 15-30 只 Pal。**Palbox 的覆盖范围就是基地半径**——这也是社区反馈「基地太小」的根源，摆建筑时要先看好范围。

- 升级 Palbox 可扩大容量和工作位
- 据点 Pal 过多会导致卡顿，别贪多

## 12 种工作适应性（Work Suitability）

每只 Pal 有 0-4 级的工作适应性，等级越高效率越高（如采矿 Lv3 比 Lv1 快 3 倍）：

| 工作类型 | 英文 | 说明 |
|---------|------|------|
| 生火 | Kindling | 熔炉、烹饪 |
| 浇水 | Watering | 农田、水系统 |
| 种植 | Planting | 种田 |
| 发电 | Generating Electricity | 电力设施 |
| 手工 | Handiwork | 制作站加速 |
| 采集 | Gathering | 浆果、小型资源 |
| 伐木 | Lumbering | 伐木 |
| 采矿 | Mining | 矿石、石头 |
| 制药 | Medicine Production | 药品 |
| 制冷 | Cooling | 冷藏 |
| 搬运 | Transporting | 物资搬运 |
| 农业 | Farming | 牧场产出 |

| Pal | 擅长 |
|-----|------|
| Anubis 阿努比斯 | 手工 Lv4 / 采矿 Lv3（最佳全能工人） |

## SAN 管理与 Pal 状态

SAN（Sanity，理智值）低的 Pal 会工作变慢、生病、最终罢工。保持 SAN 靠三件事：

1. **床**：提供足够床位
2. **食物**：喂食箱保持充足，别断粮
3. **温泉 Hot Spring**：让 Pal 恢复理智

> 提示：低 SAN 是「Pal 不干活」的最常见原因，先查床、食物、温泉，别急着换 Pal。

## 基地防御

定期会有敌对阵营或野生 Pal 突袭基地：

- 建围墙 + 留 1-2 个缺口（choke point）聚怪
- 缺口处放防御设施（弩炮、机枪塔）
- 派驻战斗型 Pal 防守

## 高效布局技巧

- **垂直堆叠**：往高处盖，比横向铺开省空间
- **存储靠近生产**：仓库紧挨工作站，减少 Pal 搬运时间
- **专用基地**：采矿、伐木、养殖分开建，别混在一起

## 新手常见错误（社区高频踩坑）

1. 工作站建太多，但工人不够
2. 抓到 Pal 不手动分配工作（不会自动上岗）
3. 选址附近没有矿点，后期被迫搬家
4. 忽视 Pal 快乐度（饥饿、没床、没温泉）
5. 存储离生产站太远

> 纠正以上任意 3 条，基地产能就能翻倍。
