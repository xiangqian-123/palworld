Palworld 的 Mod 生态仅限 PC (Steam) 版本。本页介绍安装方法和推荐方向。

## 结论先行

- Mod **仅限 PC (Steam) 版本**
- PS5 / Xbox / Mac 不支持 Mod
- 官方支持 Steam 创意工坊

## 安装方式

### 方式一：Steam 创意工坊

1. 打开 Palworld 的 Steam 创意工坊页面
2. 浏览并订阅 Mod
3. 启动游戏，Mod 自动加载
4. 在游戏内管理已订阅的 Mod

### 方式二：本地手动安装

1. 下载 Mod 文件
2. 放入 Palworld 游戏目录的 Mods 文件夹
3. 在游戏启动时启用

## 推荐 Mod 方向

> 以下为方向推荐，具体 Mod 名以创意工坊实时搜索为准。

| 方向 | 说明 |
|------|------|
| 物流效率 | 优化传送带/搬运 Pal 效率 |
| 地图增强 | 显示资源点/BOSS 位置 |
| 自动化辅助 | 自动喂养/自动养殖辅助 |
| UI 改进 | 改善 Pal 管理界面 |
| 画质增强 | 画面优化 |
| QoL 工具 | 快捷操作、批量管理 |

## 兼容性注意

1. **版本更新可能导致 Mod 失效**：每次游戏更新后检查 Mod 兼容性
2. **Mod 与 EA 版本兼容**：1.0 正式版后部分旧 Mod 可能需要更新
3. **专用服务器 Mod**：服务器和客户端需要安装相同的 Mod
4. **跨平台联机**：使用 Mod 的 PC 玩家可以加入未装 Mod 的服务器（视具体 Mod 而定）

## Pal Surgery Table 改被动

1.0 版本和 Terraria 联动更新引入的 Pal Surgery Table 帕鲁手术台 是官方内置的"被动技能修改"功能：
- 可覆盖 Pal 的被动技能
- 可改变 Pal 性别
- 需要 Surgery Chip 手术芯片

> 这不是 Mod，是官方功能，所有平台可用。
