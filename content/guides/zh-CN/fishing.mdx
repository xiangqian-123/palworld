钓鱼 Fishing 是 Palworld 在 v0.6.0 Tides of Terraria 更新中新增的系统。本篇详解鱼竿制作、钓鱼点和打捞系统。

## 钓鱼前置条件

1. **更新到 v0.6.0 或更高版本**：钓鱼系统随 Terraria 联动上线
2. **制作 Fishing Rod 鱼竿**：需要特定材料（以游戏内为准）
3. **找到水域**：海边、湖泊、河流均可

## 钓鱼玩法

| 步骤 | 操作 |
|------|------|
| 1 | 装备 Fishing Rod 鱼竿 |
| 2 | 在水边使用鱼竿 |
| 3 | 观察水下的 Pal 影子 |
| 4 | 时机合适时拉杆捕获 |

可捕获的内容包括：
- 水系 Pal（如 Turtacle、Jellroy、Gloopie、Finsider 等 Terraria 联动新增 Pal）
- 鱼类食材
- 海底物资

## 打捞 Salvage 系统

打捞是钓鱼的配套系统，可从海底获取珍贵材料：

1. **骑乘水系 Pal**（如 Surfent 水蛇、Neptilius 海神龙）
2. **使用鱼竿打捞海底物资**
3. 获取 Coralum Ore 珊瑚矿、Crude Oil 原油等

### 打捞产出

| 材料 | 获取方式 | 产出 |
|------|---------|------|
| Coralum Ore 珊瑚矿 | 打捞沉船 rank 2 | 6-11/次 |
| 海底宝藏 | 打捞沉船岛周边 | 随机 |
| World Tree 钓鱼 | 世界树区域钓鱼 | 12-25 Coralum Ore |

> Coralum Ore 是地图上无矿点的特殊材料，打捞是主要获取途径之一。

## 基地钓鱼池

Fishing Pond 钓鱼池 是可在基地建造的建筑：
- 在基地内享受钓鱼乐趣
- 不需要去海边
- 可捕获部分水系 Pal

## 新增水系 Pal

Terraria 联动新增了多种水系/海洋 Pal：

| Pal | 说明 |
|-----|------|
| Turtacle | 海龟型 Pal |
| Jellroy / Jelliette | 水母型 Pal |
| Gloopie | 黏液型 Pal |
| Finsider | 鱼型 Pal |
| Ghangler | 深海型 Pal |
| Whalaska / Whalaska Ignis | 鲸鱼型 Pal |
| Neptilius | 传说级水系 Pal |

## 钓鱼技巧

1. **观察水下影**：大影 = 大鱼/稀有 Pal
2. **装备加成**：部分 Pal 被动可提升钓鱼效率
3. **天气影响**：不同天气可能出现不同 Pal
4. **时间影响**：部分水系 Pal 仅在特定时段出现
