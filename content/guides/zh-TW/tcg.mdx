## 卡牌型別

Palworld TCG 有 5 種卡牌型別：

| 型別 | 說明 |
|------|------|
| Pals 帕魯 | 核心戰鬥單位，有攻擊力和體力 |
| Gears 裝備 | 裝備給 Pal，增強能力 |
| Structures 建築 | 放置在基地區，提供功能 |
| Events 事件 | 即時效果卡 |
| Souls 靈魂 | 部署 Pal/裝備/建築的資源 |

## 玩法概要

- 牌組：50 張
- 目標：將對手 Life Counter 從 10 降至 0
- 每回合抽 2 個 Soul（上限 10）
- 用 Soul 部署卡牌到 Base 基地區
- Pal 可以攻擊對手 Pal / 建築 / 或直接 Strike 玩家
- 力量值 Power 決定戰鬥勝負，生命值 HP 每回合重置
- Strike 數決定翻轉牌數，Lucky Symbol 可免傷
