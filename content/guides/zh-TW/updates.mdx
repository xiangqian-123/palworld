Palworld 自 2024 年 1 月 19 日搶先體驗上線以來持續更新。2026 年 7 月 10 日正式釋出 1.0 版本，告別 EA 階段。本頁彙總全部版本歷史。

## 1.0 正式版核心內容

1.0 是 Palworld 迄今最大的更新：

| 內容 | 說明 |
|------|------|
| Pal 總數 | 全遊戲共 **287 種 Pal**（官方維基百科資料） |
| World Tree 世界樹 | 主線終章，終於可進入（8 座塔封印劇情） |
| Pal 覺醒/突變 | 強化 Pal 或培育突變個體（變異蛋） |
| 200+ 夥伴技能重做 | Partner Skills 大幅改進 |
| 新材料 | Hardwood、Soralite、Paloxite、World Tree Holy Water 等 |
| 等級上限 80 | 從 EA 階段提升 |
| 多人改進 | 跨平臺聯機、語音聊天、公會許可權、伺服器工具 |

## 重大更新詳解

### v0.5.0 — 跨平臺聯機（2025-03-19）
首次支援 PC / PS5 / Xbox / Mac 跨平臺聯機。房主在 World Settings 開啟 Cross-Play。

### v0.6.0 — Tides of Terraria（2025-06-25）
與 Terraria 聯動，新增 27 Pal、3 島嶼、Terraria 地下城、釣魚/打撈系統、Arena 競技場。詳見[Terraria 聯動攻略](/zh-TW/guide/terraria)。

### 1.0.0 — 正式版（2026-07-10）
最大更新。在 Summer Game Fest 2026 公佈。開放 World Tree 世界樹主線終章、Pal 覺醒/突變系統、總計 287 種 Pal。Steam 限時 25% off 慶祝。

## Nintendo 專利糾紛

Palworld 與 Nintendo（任天堂）及 The Pokémon Company 的訴訟是近年遊戲圈最大爭議之一。完整時間線：

| 時間 | 事件 |
|------|------|
| 2024-01-24 | The Pokémon Company 發宣告，稱收到大量關於"另一家公司 1 月發售遊戲"的問詢，將"調查並採取適當措施" |
| 2024-09-18 | **Nintendo + The Pokémon Company 正式向東京地方法院起訴 Pocketpair**，指控侵犯專利權（帕魯球捕捉機制類似寶可夢的捕捉機制） |
| 2024-09 | 索賠額：**兩家各 500 萬日元** + 遲延損害賠償，並要求禁令阻止 Palworld 發售 |
| 2024-11 | Pocketpair 回應"不知曉侵犯了任何專利"，併發布補丁修改了與寶可夢相似的機制 |
| 2024-12 | Nintendo 在美國提交 23 項專利，最終 **1 項獲批、其餘被駁回** |
| 2025 | Pocketpair 抗辯：Dark Souls III 的 Pocket Souls Mod 等先例使任天堂專利無效；任天堂稱"Mod 不算獨立遊戲、不構成專利侵權" |
| 2026-10-01 | 法院安排**證據陳述** |
| 2026-11-09 | 法院將**發表意見** |

> 因訴訟影響，Palworld 上 Nintendo Switch 的可能性極低；目前也暫無 PS4 版本。
