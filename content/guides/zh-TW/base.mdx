基地是 Palworld 的核心，捕捉、生產、養殖、製作都圍繞據點展開。一個規劃得當的基地能全自動產出資源，規劃差的基地則天天被突襲、Pal 罷工。本攻略從選址到自動化全流程講解。

## 基地選址（最重要的一步）

基地位置決定資源獲取效率，選址前先確認附近有什麼：

| 考量 | 建議 |
|------|------|
| 地形 | 平坦開闊地，方便擺建築 |
| 礦點 | 附近有 Ore 礦石 礦點（後期剛需） |
| 水源 | 靠近水源，方便澆灌 |
| 安全 | 避開高等級敵對 Pal 聚集區 |

> 提示：前期一個基地，後期可開多個基地分工——一個採礦、一個伐木、一個養殖，比單一「萬能基地」效率高得多。

## Palbox 與基地半徑

Palbox 帕魯箱 是據點核心，2 級解鎖，可容納 15-30 只 Pal。**Palbox 的覆蓋範圍就是基地半徑**——這也是社羣反饋「基地太小」的根源，擺建築時要先看好範圍。

- 升級 Palbox 可擴大容量和工作位
- 據點 Pal 過多會導致卡頓，別貪多

## 12 種工作適應性（Work Suitability）

每隻 Pal 有 0-4 級的工作適應性，等級越高效率越高（如採礦 Lv3 比 Lv1 快 3 倍）：

| 工作型別 | 英文 | 說明 |
|---------|------|------|
| 生火 | Kindling | 熔爐、烹飪 |
| 澆水 | Watering | 農田、水系統 |
| 種植 | Planting | 種田 |
| 發電 | Generating Electricity | 電力設施 |
| 手工 | Handiwork | 製作站加速 |
| 採集 | Gathering | 漿果、小型資源 |
| 伐木 | Lumbering | 伐木 |
| 採礦 | Mining | 礦石、石頭 |
| 製藥 | Medicine Production | 藥品 |
| 製冷 | Cooling | 冷藏 |
| 搬運 | Transporting | 物資搬運 |
| 農業 | Farming | 牧場產出 |

## SAN 管理與 Pal 狀態

SAN（Sanity，理智值）低的 Pal 會工作變慢、生病、最終罷工。保持 SAN 靠三件事：

1. **床**：提供足夠床位
2. **食物**：餵食箱保持充足，別斷糧
3. **溫泉 Hot Spring**：讓 Pal 恢復理智

> 提示：低 SAN 是「Pal 不幹活」的最常見原因，先查床、食物、溫泉，別急著換 Pal。

## 基地防禦

定期會有敵對陣營或野生 Pal 突襲基地：

- 建圍牆 + 留 1-2 個缺口（choke point）聚怪
- 缺口處放防禦設施（弩炮、機槍塔）
- 派駐戰鬥型 Pal 防守

## 高效佈局技巧

- **垂直堆疊**：往高處蓋，比橫向鋪開省空間
- **儲存靠近生產**：倉庫緊挨工作站，減少 Pal 搬運時間
- **專用基地**：採礦、伐木、養殖分開建，別混在一起

## 新手常見錯誤（社羣高頻踩坑）

1. 工作站建太多，但工人不夠
2. 抓到 Pal 不手動分配工作（不會自動上崗）
3. 選址附近沒有礦點，後期被迫搬家
4. 忽視 Pal 快樂度（飢餓、沒床、沒溫泉）
5. 儲存離生產站太遠

> 糾正以上任意 3 條，基地產能就能翻倍。
