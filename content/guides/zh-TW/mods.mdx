Palworld 的 Mod 生態僅限 PC (Steam) 版本。本頁介紹安裝方法和推薦方向。

## 結論先行

- Mod **僅限 PC (Steam) 版本**
- PS5 / Xbox / Mac 不支援 Mod
- 官方支援 Steam 創意工坊

## 安裝方式

### 方式一：Steam 創意工坊

1. 開啟 Palworld 的 Steam 創意工坊頁面
2. 瀏覽並訂閱 Mod
3. 啟動遊戲，Mod 自動載入
4. 在遊戲內管理已訂閱的 Mod

### 方式二：本地手動安裝

1. 下載 Mod 檔案
2. 放入 Palworld 遊戲目錄的 Mods 資料夾
3. 在遊戲啟動時啟用

## 推薦 Mod 方向

> 以下為方向推薦，具體 Mod 名以創意工坊實時搜尋為準。

| 方向 | 說明 |
|------|------|
| 物流效率 | 最佳化傳送帶/搬運 Pal 效率 |
| 地圖增強 | 顯示資源點/BOSS 位置 |
| 自動化輔助 | 自動餵養/自動養殖輔助 |
| UI 改進 | 改善 Pal 管理介面 |
| 畫質增強 | 畫面最佳化 |
| QoL 工具 | 快捷操作、批次管理 |

## 相容性注意

1. **版本更新可能導致 Mod 失效**：每次遊戲更新後檢查 Mod 相容性
2. **Mod 與 EA 版本相容**：1.0 正式版後部分舊 Mod 可能需要更新
3. **專用伺服器 Mod**：伺服器和客戶端需要安裝相同的 Mod
4. **跨平臺聯機**：使用 Mod 的 PC 玩家可以加入未裝 Mod 的伺服器（視具體 Mod 而定）

## Pal Surgery Table 改被動

1.0 版本和 Terraria 聯動更新引入的 Pal Surgery Table 帕魯手術檯 是官方內建的"被動技能修改"功能：
- 可覆蓋 Pal 的被動技能
- 可改變 Pal 性別
- 需要 Surgery Chip 手術晶片

> 這不是 Mod，是官方功能，所有平臺可用。
