釣魚 Fishing 是 Palworld 在 v0.6.0 Tides of Terraria 更新中新增的系統。本篇詳解魚竿製作、釣魚點和打撈系統。

## 釣魚前置條件

1. **更新到 v0.6.0 或更高版本**：釣魚系統隨 Terraria 聯動上線
2. **製作 Fishing Rod 魚竿**：需要特定材料（以遊戲內為準）
3. **找到水域**：海邊、湖泊、河流均可

## 釣魚玩法

| 步驟 | 操作 |
|------|------|
| 1 | 裝備 Fishing Rod 魚竿 |
| 2 | 在水邊使用魚竿 |
| 3 | 觀察水下的 Pal 影子 |
| 4 | 時機合適時拉桿捕獲 |

可捕獲的內容包括：
- 水系 Pal（如 Turtacle、Jellroy、Gloopie、Finsider 等 Terraria 聯動新增 Pal）
- 魚類食材
- 海底物資

## 打撈 Salvage 系統

打撈是釣魚的配套系統，可從海底獲取珍貴材料：

1. **騎乘水系 Pal**（如 Surfent 水蛇、Neptilius 海神龍）
2. **使用魚竿打撈海底物資**
3. 獲取 Coralum Ore 珊瑚礦、Crude Oil 原油等

### 打撈產出

| 材料 | 獲取方式 | 產出 |
|------|---------|------|
| Coralum Ore 珊瑚礦 | 打撈沉船 rank 2 | 6-11/次 |
| 海底寶藏 | 打撈沉船島周邊 | 隨機 |
| World Tree 釣魚 | 世界樹區域釣魚 | 12-25 Coralum Ore |

> Coralum Ore 是地圖上無礦點的特殊材料，打撈是主要獲取途徑之一。

## 基地釣魚池

Fishing Pond 釣魚池 是可在基地建造的建築：
- 在基地內享受釣魚樂趣
- 不需要去海邊
- 可捕獲部分水系 Pal

## 新增水系 Pal

Terraria 聯動新增了多種水系/海洋 Pal：

| Pal | 說明 |
|-----|------|
| Turtacle | 海龜型 Pal |
| Jellroy / Jelliette | 水母型 Pal |
| Gloopie | 黏液型 Pal |
| Finsider | 魚型 Pal |
| Ghangler | 深海型 Pal |
| Whalaska / Whalaska Ignis | 鯨魚型 Pal |
| Neptilius | 傳說級水系 Pal |

## 釣魚技巧

1. **觀察水下影**：大影 = 大魚/稀有 Pal
2. **裝備加成**：部分 Pal 被動可提升釣魚效率
3. **天氣影響**：不同天氣可能出現不同 Pal
4. **時間影響**：部分水系 Pal 僅在特定時段出現
