Palworld 1.0 正式版把等級上限提高到 80 級，主線終點是 World Tree 世界樹。本攻略覆蓋終局主線、核心材料、傳說裝備、修復成本與困難模式，幫你從「通關」走到「畢業」。

## 主線終章：World Tree 世界樹

自 EA 首發就能遠遠看到卻無法進入的巨大樹木，1.0 正式版開放進入，是主線故事的終點。

- **8 座塔 + 8 個 Key Sphere** 共同封印著世界樹深淵中的「災厄」
- 需擊敗各陣營塔 BOSS 後，才能進入世界樹
- 世界樹內掉落 World Tree Holy Water 世界樹聖水、Mythical Wood 神話木 等終局材料

## 終局核心材料

| 材料 | 獲取方式 | 主要用途 |
|------|---------|---------|
| World Tree Holy Water 世界樹聖水 | 世界樹副本掉落 | 終極藥水、Paloxite 錠 |
| Mythical Wood 神話木 | 遠古巨樹 / 遠古聖物回收 | 終極裝備 |
| Soralite | Soralite Quarry 開採（終局區域） | Soralite 錠（大量下游配方） |
| Paloxite | 遠古聖物回收 | Paloxite 錠（終極裝備） |
| Chromite 鉻礦 | 遠古材料合成器 / Silvegis 擊殺 | Hexolite（後期武器） |
| Coralum Ore 珊瑚礦 | 海底打撈 / 石油平臺箱子 | 珊瑚錠（水下裝備） |
| Ancient Civilization Core 古代文明核心 | BOSS 戰掉落 | AI Core 等終極科技 |

> 提示：前期優先囤積 Hardwood 硬木 和 Ancient Civilization Parts 古代文明部件，後期需求最大。

## 傳說圖紙 Legendary Schematics

傳說圖紙是終局裝備的核心，主要透過以下方式獲取：

- 擊敗 Alpha Pal（固定重新整理的大體型 Pal）有機率掉落對應傳說圖紙
- 擊殺/捕捉 Alpha Pal 時順便攢「珍貴」物品賣錢（見[賺錢攻略](/zh-TW/guide/money)）

## 裝備修復成本（終局最容易被忽視的坑）

終局武器修復成本會**大幅上升**。以火箭筒 Rocket Launcher 為例，單次修復需要大量 Pal Metal Ingot 帕魯金屬錠 和 Polymer 聚合物，遠超中前期武器。

> 社羣反饋：終局武器「修復成本懲罰性」是高頻吐槽點。解決辦法是讓礦場持續自動產出 Pal Metal Ingot 所需材料，別等要修了才去現採。

- **Pal Metal Ingot 帕魯金屬錠**：由 Ore 礦石 + Paldium Fragment 帕魯碎片 合成
- **Polymer 聚合物**：2 High Quality Pal Oil + 1 Sulfur 硫磺

## 困難模式 BOSS

擊敗 6 個塔 BOSS 後，可解鎖困難模式 Hard Mode：

- 困難模式 BOSS 等級、血量、傷害全面上升
- 掉落更高階的傳說圖紙和材料
- 需要滿配 Pal 隊伍 + 屬性剋制 + 頂級裝備

## 終局配裝思路

| 部位 | 方向 |
|------|------|
| 武器 | 傳說圖紙武器（高面板） |
| 護甲 | 高防禦 + 屬性抗性 |
| 戰鬥 Pal | 屬性剋制 + Rank 4 被動（Legend + Musclehead 等） |
| 坐騎 | 高速飛行坐騎（趕路/繞後） |
