Palworld 1.0 正式版共有 287 種 Pal 幻獸，涵蓋 9 大元素屬性。本頁是 Pal 圖鑑導航，含分類索引和最佳推薦。

## Pal 屬性分類

Palworld 的 Pal 分為以下元素屬性：

| 屬性 | 說明 | 代表 Pal |
|------|------|---------|
| Neutral 無屬性 | 基礎屬性，無剋制關係 | Cattiva、Lamball |
| Fire 火 | 剋制 Grass/Ice | Foxparks、Blazehowl |
| Water 水 | 剋制 Fire | Azurobe、Penking |
| Grass 草 | 剋制 Ground | Lifmunk、Robinquill |
| Electric 電 | 剋制 Water | Sparkit、Orserk |
| Ice 冰 | 剋制 Dragon | Foxcicle、Frostallion |
| Ground 地 | 剋制 Electric | Rushoar、Digtoise |
| Dark 暗 | 剋制 Neutral | Daedream、Maraith |
| Dragon 龍 | 剋制 Dark | Jetragon、Quivern |

## Pal 獲取方式

| 方式 | 說明 |
|------|------|
| 野外捕獲 | 用 Pal Sphere 帕魯球 捕獲野生 Pal |
| 養殖 | 在 Breeding Farm 養殖場配對獲得 |
| BOSS 掉落 | 擊敗塔 BOSS / 突襲 BOSS |
| 任務獎勵 | 完成特定任務獲得 |
| 特殊位置 | 傳說 Pal 固定重新整理點 |

> Pal 沒有**進化系統**。變體形態（如 Mossanda Lux、Jormuntide Ignis）是獨立物種，需單獨捕獲或養殖。
