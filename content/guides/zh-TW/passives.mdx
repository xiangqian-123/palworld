每個 Pal 最多擁有 4 個被動技能 Passive Skills，提供攻擊、防禦、工作速度、移動速度、理智等加成或負面效果。全遊戲共 **115 個被動技能：100 個正面 + 15 個負面**，其中 **40 個可透過 Pal Surgery 夥伴手術直接賦予**。稀有度從 **Rank 5（世界樹套裝，最強）到 Rank -3（最差）**。

> 資料基於 1.0 版本遊戲檔案，更新於 2026 年 7 月。

## 被動技能如何運作

1. **四個插槽**：野生 Pal 和孵化的蛋最多隨機獲得 4 個被動技能，空槽位保留到透過繁殖或手術填充。
2. **繁殖是主要獲取途徑**：子代會隨機繼承父母雙方的被動，幾代之後可把目標被動疊加到同一只 Pal 上。
3. **手術覆蓋**：帶「🔪」標記的被動可用 Pal Surgery 夥伴手術直接賦予，無需重新繁殖——包括 Rank 5 世界樹套裝和多數 Rank 4 被動。

## 最佳 4 被動組合（1.0 版本）

### 純 DPS 戰鬥
```
Legend + Musclehead + Serenity + 30%元素被動
```
> 1.0 之後 Serenity（冷卻 -30% + 攻擊 +10%）已取代舊版 Ferocious/Brave 組合。

### 元素輸出戰鬥
```
Legend + Musclehead + 30%元素被動 + Impatient
```

### 坦克 / 生存
```
Legend + Diamond Body + Burly Body + Stronghold Strategist
```

### 速度坐騎
```
Swift + Runner + Legend + 無限耐力/靈巧
```

### 終極基地工人
```
Artisan + Work Slave + Serious + Remarkable Craftsmanship
```
> 工作速度：基礎 70 × 215%（被動）× 130%（強化）= 約 195。4 星濃縮後各工作適性 +1，每級適性比上一級快 3 倍（Lv1→Lv5 約 81 倍）。

## 被動繼承規則

1. 合併雙親被動（去重）後，擲"繼承數"（1–4，機率 40%/30%/20%/10%）
2. **雙親有相同被動對機率無幫助也無害**
3. 繼承全部目標被動的機率：1 個 40%、2 個 24%、3 個 12%、4 個 10%
4. 最佳做法：雙親合計只留 4 個目標被動（2+2 / 3+1 / 4+0）
5. **Legend、元素 Emperor 不能隨機突變**，必須從父母繼承

詳見[養殖攻略](/zh-TW/guide/breeding)。

## Pal Surgery Table 修改被動

v0.6.0 引入的 Pal Surgery Table 帕魯手術檯 可以：
- 覆蓋現有被動技能（花金幣，部分被動需植入物）
- 改變 Pal 性別
- Serious / Nocturnal / Philanthropist / Workaholic 等關鍵被動可直接植入（無需先獲得植入物）

> 所有平臺可用（不僅 PC），這是官方內建功能。
