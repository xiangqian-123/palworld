每個 Pal 最多擁有 0–4 個被動技能 Passive Skills，提供攻擊、防禦、工作速度、移動速度、理智等加成或負面效果。被動按稀有度分為 **Rank 4（彩虹階，最強）→ Rank -3（最差）** 共 7 檔。

## 被動分級（權威 Rank 體系）

### Rank 4（彩虹階，最強）

| 被動 | 核心效果 |
|------|---------|
| Legend 傳說 | +攻擊 / +防禦 / +移速（傳說 Pal 專屬） |
| Demon God 魔神 | +攻擊 / +防禦（0.4.11 新增） |
| Diamond Body 鑽石之軀 | +防禦 |
| Eternal Engine 永動機 | 耐力相關 |
| Vampiric 吸血鬼 | 吸血 |
| Invader 入侵者 | 攻擊相關 |
| Swift 迅捷 | +移速（0.4.11 提升為彩虹階） |
| Siren of the Void 虛空塞壬 | +30% 暗屬性傷害 |
| Remarkable Craftsmanship 神匠 | **+75% 工作速度**（終極工人） |
| Lucky 幸運 | +工作速度 / +攻擊 |
| King of the Waves 浪之王 | 水中坐騎加成 |
| Lunker / Ranch Master / Savior 等 | 釣魚 / 牧場 / 生存 |

### Rank 3（強力）

Artisan 工匠、Burly Body 壯碩、Workaholic 工作狂、Serenity 寧靜、Ferocious 兇猛、Runner 奔跑者、Noble 貴族、Philanthropist 慈善家、Motivational Leader 激勵領袖、Stronghold Strategist 要塞戰略家、Vanguard 先鋒、無限耐力、以及元素強化系（見下）。

### Rank 2

Musclehead 蠻力（+攻擊 / -工作速度，純戰鬥）。

### Rank 1（普通/雙刃）

Brave 勇敢、Serious 認真、Work Slave 工作奴、Impatient 急躁、Nimble 靈巧、Fine Furs 華貴毛皮、Insomnia 失眠 等數十種。

### 負面被動（Rank -1 ~ -3）

Clumsy 笨拙、Coward 懦弱、Slacker 偷懶、Pacifist 和平主義、Brittle 脆弱、Destructive 破壞、Glutton 暴食 等。

## 關鍵被動效果說明（易錯點）

| 被動 | 正確效果 | 常見誤傳 |
|------|---------|---------|
| Serenity 寧靜 | 主動技能冷卻 -30% + 攻擊 +10% | ❌ 誤傳為"理智恢復" |
| Philanthropist 慈善家 | 提升**配種速度**（養殖計時） | ❌ 誤傳為"牧場產蛋" |
| Remarkable Craftsmanship 神匠 | +75% 工作速度（彩虹階） | ❌ 誤傳為"Golden Touch"（不存在） |
| Siren of the Void 虛空塞壬 | +30% 暗屬性 | ❌ 誤傳為"Shadow Ruler"（不存在） |

元素強化被動按元素分 9 系，是"元素輸出"流的核心：

| 被動 | 對應元素 |
|------|---------|
| Flame Emperor 炎帝 | Fire 火 |
| Ice Emperor 冰帝 | Ice 冰 |
| Earth Emperor 地帝 | Ground 地 |
| Lord of Lightning 雷之領主 | Electric 電 |
| Lord of the Sea 海之領主 | Water 水 |
| Lord of the Underworld 冥界領主 | Dark 暗 |

## 最佳 4 被動組合（1.0 版本）

### 純 DPS 戰鬥
```
Legend + Musclehead + Serenity + 30%元素被動
```
> 1.0 之後 Serenity（冷卻 -30% + 攻擊 +10%）已取代舊版 Ferocious/Brave 組合。

### 元素輸出戰鬥
```
Legend + Musclehead + 30%元素被動 + Impatient
```

### 坦克 / 生存
```
Legend + Diamond Body + Burly Body + Stronghold Strategist
```

### 速度坐騎
```
Swift + Runner + Legend + 無限耐力/靈巧
```

### 終極基地工人
```
Artisan + Work Slave + Serious + Remarkable Craftsmanship
```
> 工作速度：基礎 70 × 215%（被動）× 130%（強化）= 約 195。4 星濃縮後各工作適性 +1，每級適性比上一級快 3 倍（Lv1→Lv5 約 81 倍）。

## 被動繼承規則

1. 合併雙親被動（去重）後，擲"繼承數"（1–4，機率 40%/30%/20%/10%）
2. **雙親有相同被動對機率無幫助也無害**
3. 繼承全部目標被動的機率：1 個 40%、2 個 24%、3 個 12%、4 個 10%
4. 最佳做法：雙親合計只留 4 個目標被動（2+2 / 3+1 / 4+0）
5. **Legend、元素 Emperor 不能隨機突變**，必須從父母繼承

詳見[養殖攻略](/zh-TW/guide/breeding)。

## World Tree 世界樹專屬被動

World Tree 區域有獨特的被動獲取途徑：
- 捕捉帶藍色光暈的野生 Pal
- 用 Ancient Relic Recycler 回收遠古聖物換 Disposable Implants
- 孵化世界樹中的 Ominous Egg

變異蛋會孵出帶**變異專屬被動**的 Pal：Babysitter、Heavily Armored、Idiosyncratic、Immortality、Skymarcher。

## Pal Surgery Table 修改被動

v0.6.0 引入的 Pal Surgery Table 帕魯手術檯 可以：
- 覆蓋現有被動技能（花金幣，部分被動需植入物）
- 改變 Pal 性別
- Serious / Nocturnal / Philanthropist / Workaholic 等關鍵被動可直接植入（無需先獲得植入物）

> 所有平臺可用（不僅 PC），這是官方內建功能。
