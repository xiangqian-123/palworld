Экосистема модов Palworld существует только для версии на PC (Steam). На этой странице описаны способы установки и рекомендуемые направления.

## Главное сразу

- Моды доступны **только в версии для PC (Steam)**
- PS5 / Xbox / Mac моды не поддерживают
- Официально поддерживается Steam Workshop

## Способы установки

### Способ 1: Steam Workshop

1. Откройте страницу Palworld в Steam Workshop
2. Просмотрите список и подпишитесь на моды
3. Запустите игру — моды загрузятся автоматически
4. Управляйте подписками прямо в игре

### Способ 2: локальная установка вручную

1. Скачайте файл мода
2. Поместите его в папку Mods в каталоге игры Palworld
3. Включите его при запуске игры

## Рекомендуемые направления модов

> Ниже даны направления, а конкретные названия модов ищите непосредственно в Workshop.

| Направление | Описание |
|------|------|
| Эффективность логистики | Оптимизация конвейеров и эффективности Палов-носильщиков |
| Улучшение карты | Отображение точек ресурсов и расположения боссов |
| Помощь в автоматизации | Автоматическое кормление и помощь в разведении |
| Улучшения UI | Улучшение интерфейса управления Палами |
| Улучшение графики | Оптимизация картинки |
| Инструменты QoL | Быстрые действия, массовое управление |

## Замечания о совместимости

1. **Обновления версий могут ломать моды**: после каждого обновления игры проверяйте совместимость модов
2. **Совместимость модов с версией раннего доступа**: после выхода 1.0 часть старых модов может требовать обновления
3. **Моды на выделенном сервере**: на сервере и клиенте должны быть установлены одни и те же моды
4. **Кросс-платформенная игра**: игроки на PC с модами могут подключаться к серверам без модов (зависит от конкретного мода)

## Изменение пассивок через Pal Surgery Table

Pal Surgery Table (паловый операционный стол), добавленный в версии 1.0 и обновлении с коллаборацией Terraria, — это встроенная официальная функция «изменения пассивных навыков»:

- Позволяет перезаписать пассивные навыки Пала
- Позволяет изменить пол Пала
- Требует Surgery Chip (операционный чип)

> Это не мод, а официальная функция, доступная на всех платформах.
