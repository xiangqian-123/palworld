Palworld доступна на PlayStation 5. На этой странице описаны покупка версии для PS5, сетевая игра и важные нюансы.

## Главное сразу

- На PS5 Palworld **есть**: покупается в PlayStation Store за $29.99
- На PS4 Palworld **нет**: версии для PS4 не существует
- PS5 поддерживает **кросс-платформенную игру** (совместимость с PC, Xbox и Mac)
- Выделенные серверы для PS5 появились после обновления v0.6.0 (Tides of Terraria)

## Как купить

Найдите Palworld в PlayStation Store и купите игру для загрузки. Поддерживается консоль PS5, обратной совместимости с PS4 нет.

## Кросс-платформенная игра

Игроки на PS5 могут играть вместе с такими платформами:

| Платформа | Сетевая игра |
|------|------|
| PC (Steam) | Поддерживается |
| Xbox Series X|S / One | Поддерживается |
| Mac | Поддерживается |
| Nintendo Switch | Не поддерживается |

Хосту нужно зайти в World Settings, включить Cross-Play и поделиться кодом приглашения.

## Отличия версий для PS5 и Steam

| Параметр | PS5 | Steam |
|------|-----|------|
| Поддержка модов | Нет | Есть |
| Выделенный сервер | Есть (с v0.6) | Есть |
| Кросс-платформенная игра | Есть | Есть |
| Опыт с геймпадом | Тактильная отдача DualSense | Нужен внешний геймпад |
| Облачные сохранения | Облако PlayStation | Облако Steam |
| Перенос сохранений между платформами | Не поддерживается | Не поддерживается |

> Внимание: Palworld **не поддерживает перенос сохранений между платформами**. Сохранение привязано к платформе, на которой создано, а Global Palbox позволяет переносить Палов только между устройствами одной платформы в рамках одного аккаунта.

## Частые вопросы про PS5

### В: Можно ли играть на PS4?
Нет. Версии Palworld для PS4 не существует, игроки на PS4 не могут ни установить игру, ни подключиться к серверам.

### В: Бывают ли скидки на версию для PS5?
Иногда игра участвует в распродажах PlayStation Store — следите за страницей магазина.

### В: Контент версии для PS5 совпадает с версией для PC?
В официальной версии 1.0 контент полностью идентичен. Различия только в модах и способе управления.
