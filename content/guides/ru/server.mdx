Palworld поддерживает выделенные серверы (Dedicated Server) с одновременным подключением до 32 игроков. На этой странице описаны способы настройки.

## Главное сразу

- На PC (Steam) можно поднять выделенный сервер
- Выделенные серверы для PS5 появились после обновления v0.6.0
- Максимум 32 игрока одновременно
- Поддерживается кросс-платформенная игра (нужно включить Cross-Play)
- В игре по приглашению максимум 4 человека, и сессия закрывается, когда хост выходит

## Способы настройки

### Способ 1: локальный сервер

1. Найдите в инструментах Steam «Palworld Dedicated Server» и установите
2. Запустите серверную программу
3. Настройте PalWorldSettings.ini
4. Откройте порт 8211 (UDP)

### Способ 2: сторонний хостинг серверов

| Провайдер | Особенности |
|--------|------|
| Shockbyte | Специализируется на серверах Palworld |
| Другие хостинги | Поддерживают развёртывание в один клик |

## Ключевые параметры PalWorldSettings.ini

| Параметр | Описание | Значение по умолчанию |
|------|------|--------|
| ServerName | Название сервера | - |
| ServerPassword | Пароль сервера | Нет |
| MaxPlayers | Максимум игроков | 32 |
| PublicPort | Порт | 8211 |
| bIsPvP | Режим PvP | false |
| bCanPickupOtherGuildDeathPenalty | Подбор предметов, потерянных при смерти игроками других гильдий | false |
| DropItemMaxNum | Лимит выпавших предметов | 3000 |
| EggIncubationSpeed | Скорость инкубации яиц | 1 |

## Настройка кросс-платформенной игры

Чтобы выделенный сервер поддерживал кросс-платформенную игру, нужно:

1. Использовать серверную программу версии EOS (Epic Online Services)
2. Включить Cross-Play в конфигурации сервера
3. Поделиться названием сервера или кодом приглашения

## Приёмы администрирования сервера

1. **Регулярно делайте резервные копии сохранений**: сохранения сервера лежат в каталоге `Pal/Saved/`
2. **Настройте скорость инкубации яиц**: значение 30–50x сильно ускоряет разведение
3. **Настройте автоматический перезапуск**: чтобы избежать утечек памяти при долгой работе
4. **Контролируйте количество Палов**: слишком высокое значение DropItemMaxNum приводит к лагам

## Серверы для PS5

Выделенные серверы для PS5 появились после обновления v0.6.0 (Tides of Terraria). Игроки на PS5 могут подключаться к серверам EOS, размещённым на PC.

## Частые вопросы

### В: Чем игра по приглашению отличается от выделенного сервера?
В игре по приглашению максимум 4 человека, и сессия закрывается, когда хост выходит. Выделенный сервер вмещает 32 человека и работает круглосуточно.

### В: Как обновлять сервер?
Инструменты Steam обновляют серверную программу автоматически. Обновление вручную: SteamCMD + app_update.

### В: Можно ли переносить сохранение между серверами?
Файлы сохранений можно скопировать вручную. Но между платформами сохранения несовместимы.
