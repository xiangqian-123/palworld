## メインクエスト終章：World Tree 世界樹

EA の配信当初から遠くに見えながら入れなかった巨大な木です。1.0正式版で入場が開放され、メインストーリーの終着点となります：

- **8つの塔 + 8つの Key Sphere** が世界樹の深淵にある「災厄」を封印している
- ストーリーには Aurie、Zenara、Astralium、Pantalus（最後の守護クジラ）などのキャラクターが関わる
- 各勢力のタワーBOSSを倒した後でなければ、世界樹に入れない
- 世界樹内では World Tree Holy Water（世界樹の聖水）、Mythical Wood（神話の木）などの終盤素材がドロップする

## 勢力とタワーBOSSの分布

Palpagos 諸島には 7 大勢力があり、それぞれ1つの塔を支配しています：

| 勢力 | リーダー | 拠点 |
|------|----------|------|
| Rayne Syndicate（レイーンシンジケート） | Zoe Rayne | 低レベルエリア / Bamboo Groves / Oil Rig |
| Free Pal Alliance（自由パル同盟） | Lily Everhart | Crescent Moon Shore / Verdant Brook |
| Brothers of the Eternal Pyre（永遠の炎の兄弟団） | Axel Travers | Mount Obsidian |
| Palpagos Islands Defense Force (PIDF) | Marcus Dryden | 各集落 / 禁猟区 |
| PAL Genetic Research Unit（PAL遺伝子研究班） | Victor Ashford | Astral Mountains |
| Moonflower Clan（月花一族） | Saya Kurosaki | Sakurajima |
| Feybreak Warriors（フェイブレイク戦士団） | Bjorn Seligsson | Feybreak |

## 探索のアドバイス

1. **序盤**：Windswept Hills のスタート地点でレベル15まで上げ、火山/雪山/砂漠に早く入らないこと
2. **中盤**：飛行マウントを解放した後に遠方のバイオームを探索する
3. **後期**：World Tree（世界樹）周辺の終盤エリアに入り、Soralite（ソラライト、Soralite Quarry で採掘）などの終盤素材を採取する
4. **終盤**：各タワーBOSSを倒す → World Tree（世界樹）に入り災厄に挑む

## BOSS の分布

Palworld には複数の BOSS がいます：

| 種類 | 説明 |
|------|------|
| Faction Leaders（タワーBOSS） | 7大勢力のリーダー。それぞれパートナーパルを連れ、10分の制限時間付き。6体倒すとハードモードに挑戦可能 |
| Raid Bosses（レイドBOSS） | 拠点に召喚される強力なパル。防衛の準備が必要 |
| Bounty Targets（懸賞ターゲット） | 名前付きの人間の敵。Successful Bounty Token をドロップ |
| Alpha Pals（アルファパル） | 固定リポップする大型パル |
| Predator Pals（捕食者パル） | 0.4.11 で追加された狂暴化パル |
