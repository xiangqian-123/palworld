Palworld は 2024年1月19日のアーリーアクセス配信以来、継続的に更新されています。2026年7月10日に 1.0 バージョンを正式リリースし、EA 段階を脱しました。本ページでは全バージョン履歴をまとめます。

## 1.0 正式版の核心コンテンツ

1.0 は Palworld 史上最大のアップデートです：

| 内容 | 説明 |
|------|------|
| パル総数 | ゲーム全体で計 **288種のパル**（公式ウィキペディアのデータ） |
| World Tree 世界樹 | メインクエストの終章。ついに入場可能（8つの塔の封印ストーリー） |
| パルの覚醒/突然変異 | パルを強化、または突然変異個体を育成（突然変異タマゴ） |
| 200以上のパートナースキルの刷新 | Partner Skills が大幅に改善 |
| 新素材 | Hardwood、Soralite、Paloxite、World Tree Holy Water など |
| レベル上限 80 | EA 段階から引き上げ |
| マルチプレイ改善 | クロスプレイ、音声チャット、ギルド権限、サーバーツール |

## 重大アップデート詳解

### v0.5.0 — クロスプレイ（2025-03-19）
初めて PC / PS5 / Xbox / Mac のクロスプレイに対応。ホストが World Settings で Cross-Play を有効にします。

### v0.6.0 — Tides of Terraria（2025-06-25）
Terraria とコラボし、新パル27種、新島3つ、Terraria のダンジョン、釣り/引き揚げシステム、Arena 闘技場を追加。詳細は[Terraria コラボガイド](/ja/guide/terraria)を参照。

### 1.0.0 — 正式版（2026-07-10）
最大のアップデート。Summer Game Fest 2026 で発表。World Tree（世界樹）のメインクエスト終章、パルの覚醒/突然変異システム、計288種のパルを開放。Steam の期間限定25%オフで記念。

## Nintendo 特許紛争

Palworld と Nintendo（任天堂）および The Pokémon Company の訴訟は、近年のゲーム業界で最大の論争の1つです。完全なタイムライン：

| 時期 | 出来事 |
|------|--------|
| 2024-01-24 | The Pokémon Company が声明を発表。「別の企業が1月に発売したゲーム」について多数の問い合わせを受けており、「調査し適切な措置を取る」とした |
| 2024-09-18 | **Nintendo ＋ The Pokémon Company が東京地方裁判所に Pocketpair を正式提訴**。パルスフィアの捕獲メカニズムがポケモンの捕獲メカニズムに類似しているとして特許権侵害を主張 |
| 2024-09 | 請求額：**各社500万円** ＋ 遅延損害賠償。および Palworld の販売を禁ずる差し止めを要求 |
| 2024-11 | Pocketpair は「いかなる特許も侵害していないことを知らない」と回答し、ポケモンに類似したメカニズムを修正するパッチをリリース |
| 2024-12 | Nintendo は米国で23件の特許を出願、最終的に**1件のみ認められ、残りは棄却** |
| 2025 | Pocketpair の抗弁：Dark Souls III の Pocket Souls Mod などの先例により任天堂の特許は無効。任天堂は「Mod は独立したゲームではなく、特許侵害に当たらない」と主張 |
| 2026-10-01 | 裁判所が**証拠の陳述**を予定 |
| 2026-11-09 | 裁判所が**意見を発表**予定 |

> 訴訟の影響で、Palworld が Nintendo Switch に登場する可能性は極めて低いです。現在、PS4 版もありません。
