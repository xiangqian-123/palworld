Palworld 1.0正式版はレベル上限を80に引き上げ、メインクエストの終着点は World Tree（世界樹）です。本ガイドは終盤のメインクエスト、核心素材、伝説装備、修理コスト、ハードモードを網羅し、「クリア」から「卒業」までをサポートします。

## メインクエスト終章：World Tree 世界樹

EA の配信当初から遠くに見えながら入れなかった巨大な木ですが、1.0正式版で入場が開放され、メインストーリーの終着点となります。

- **8つの塔 + 8つの Key Sphere** が世界樹の深淵にある「災厄」を封印している
- 各勢力のタワーBOSSを倒した後でなければ、世界樹に入れない
- 世界樹内では World Tree Holy Water（世界樹の聖水）、Mythical Wood（神話の木）などの終盤素材がドロップする

## 終盤の核心素材

| 素材 | 入手方法 | 主な用途 |
|------|----------|----------|
| World Tree Holy Water（世界樹の聖水） | 世界樹のダンジョンでドロップ | 究極の薬、Paloxite インゴット |
| Mythical Wood（神話の木） | 古代の巨木 / 古代の聖物のリサイクル | 究極装備 |
| Soralite（ソラライト） | Soralite Quarry（ソラライト採掘場）で採掘（終盤エリア） | Soralite インゴット（多数の下流レシピ） |
| Paloxite（パロキサイト） | 古代の聖物のリサイクル | Paloxite インゴット（究極装備） |
| Chromite（クロマイト） | 古代素材合成機 / Silvegis の撃殺 | Hexolite（後期武器） |
| Coralum Ore（サンゴ鉱石） | 海底引き揚げ / 石油プラットフォームの宝箱 | サンゴインゴット（水中装備） |
| Ancient Civilization Core（古代文明のコア） | BOSS戦でドロップ | AI Core などの究極テクノロジー |

> ヒント：序盤のうちに Hardwood（硬木）と Ancient Civilization Parts（古代文明の部品）を溜めておくこと。後期の需要が最も大きいです。

## 伝説の設計図 Legendary Schematics

伝説の設計図は終盤装備の核心で、主に以下の方法で入手します：

- Alpha Pal（固定リポップする大型パル）を倒すと、対応する伝説の設計図がドロップすることがある
- Alpha Pal を倒す/捕まえるついでに「貴重」アイテムを集めて売って稼ぐ（[稼ぎガイド](/ja/guide/money)参照）

## 装備の修理コスト（終盤で最も見落とされやすい罠）

終盤武器の修理コストは**大幅に上昇**します。Rocket Launcher（ロケットランチャー）を例に取ると、1回の修理に大量の Pal Metal Ingot（パルメタルインゴット）と Polymer（ポリマー）が必要で、中前期の武器をはるかに超えます。

> コミュニティの声：終盤武器の「修理コストが罰則的」なのは高頻度の不満点です。解決策は、鉱山で Pal Metal Ingot に必要な素材を常時自動生産しておくこと。修理が必要になってから慌てて採取しないこと。

- **Pal Metal Ingot（パルメタルインゴット）**：Ore（鉱石） + Paldium Fragment（パルジウムの欠片）から合成
- **Polymer（ポリマー）**：2 High Quality Pal Oil（高品質パルオイル） + 1 Sulfur（硫黄）

## ハードモードのBOSS

6つのタワーBOSSを倒すと、ハードモード Hard Mode を解放できます：

- ハードモードのBOSSはレベル・HP・ダメージが総じて上昇
- より上位の伝説の設計図と素材がドロップ
- フル装備のパルパーティ + 属性相性 + 最上位装備が必要

## 終盤の装備構成方針

| 部位 | 方向 |
|------|------|
| 武器 | 伝説の設計図武器（高い数値） |
| 防具 | 高防御 + 属性耐性 |
| 戦闘パル | 属性相性 + Rank 4 パッシブ（Legend + Musclehead など） |
| マウント | 高速飛行マウント（移動・背後取り） |
