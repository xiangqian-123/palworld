各パルは最大 4 つのパッシブスキル Passive Skills を持ち、攻撃・防御・作業速度・移動速度・理性などに加算またはマイナス効果をもたらします。ゲーム全体で **115 種のパッシブスキル：100 種のプラス ＋ 15 種のマイナス** があり、そのうち **40 種は Pal Surgery（パル手術）で直接付与可能** です。希少度は **Rank 5（世界樹セット、最強）から Rank -3（最弱）** までです。

> データは 1.0 バージョンのゲームファイルに基づき、2026年7月更新。

## パッシブスキルはどう働くか

1. **4つの枠**：野生パルと孵化したタマゴは最大でランダムに4つのパッシブスキルを得られ、空き枠は配合や手術で埋まるまで保持される。
2. **配合が主な入手経路**：子は父母双方のパッシブをランダムに継承し、数世代後に目標パッシブを同一パルに重ねられる。
3. **手術での上書き**：「🔪」マーク付きのパッシブは Pal Surgery（パル手術）で直接付与でき、再配合は不要——Rank 5 の世界樹セットや大半の Rank 4 パッシブを含む。

## 重要なパッシブ効果の説明（間違いやすい点）

| パッシブ | 正しい効果 | よくある誤伝 |
|----------|------------|--------------|
| Serenity 静寂 | アクティブスキルCT -30% ＋ 攻撃 +10% | ❌ 「SAN回復」と誤伝 |
| Philanthropist 慈善家 | **配合速度**（配合タイマー）を上げる | ❌ 「牧場の産卵」と誤伝 |
| Remarkable Craftsmanship 神匠 | 作業速度 +75%（虹階） | ❌ 「Golden Touch」（存在せず）と誤伝 |
| Siren of the Void 虚無のセイレン | 闇属性 +30% ＋ 氷属性 +30% | ❌ 「Shadow Ruler」（存在せず）と誤伝 |

## 最適な4パッシブの組み合わせ（1.0版）

### 純DPS戦闘
```
Legend + Musclehead + Serenity + 30%属性パッシブ
```
> 1.0 以降、Serenity（CT -30% ＋ 攻撃 +10%）は旧版の Ferocious/Brave の組み合わせに代わる。

### 属性出力戦闘
```
Legend + Musclehead + 30%属性パッシブ + Impatient
```

### タンク / 生存
```
Legend + Diamond Body + Burly Body + Stronghold Strategist
```

### 速度マウント
```
Swift + Runner + Legend + 無限スタミナ/俊敏
```

### 究極の拠点労働者
```
Artisan + Work Slave + Serious + Remarkable Craftsmanship
```
> 作業速度：基本70 × 215%（パッシブ）× 130%（強化）＝ 約195。4星濃縮で各作業適性 +1、適性1レベル毎に上のレベルより3倍速く（Lv1→Lv5 で約81倍）。

## パッシブ継承ルール

1. 父母のパッシブを統合（重複排除）した後、「継承数」（1〜4、確率40%/30%/20%/10%）を抽選
2. **父母が同じパッシブを持っていても確率に助けにも害にもならない**
3. 目標パッシブをすべて継承する確率：1個40%、2個24%、3個12%、4個10%
4. 最良の方法：父母の合計が目標パッシブ4個だけになるようにする（2+2 / 3+1 / 4+0）
5. **Legend、属性 Emperor はランダム突然変異せず、父母から継承する必要がある**

詳細は[配合ガイド](/ja/guide/breeding)を参照。

## Pal Surgery Table（パル手術台）でのパッシブ変更

v0.6.0 で導入された Pal Surgery Table（パル手術台）は以下が可能です：
- 既存のパッシブスキルを上書き（金を消費、一部パッシブは埋め込みが必要）
- パルの性別を変更
- Serious / Nocturnal / Philanthropist / Workaholic などの重要パッシブは直接埋め込み可能（先に埋め込みを入手する必要なし）

> すべてのプラットフォームで利用可能（PCのみならず）。これは公式の内蔵機能です。
