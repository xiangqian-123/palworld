拠点は Palworld の核心であり、捕獲・生産・配合・制作のすべてが拠点を中心に展開します。計画の良い拠点は資源を全自動で生み出し、計画の悪い拠点は毎日のように襲撃され、パルがストライキを起こします。本ガイドでは立地選びから自動化までを解説します。

## 拠点の立地選び（最も重要なステップ）

拠点の位置は資源取得効率を決定します。立地を決める前に、周辺に何があるかを確認しましょう：

| 検討項目 | アドバイス |
|----------|-----------|
| 地形 | 平坦で開けた場所。建物の配置がしやすい |
| 鉱脈 | 近くに Ore（鉱石）の鉱脈があること（後期に必須） |
| 水源 | 水辺に近いこと。灌漑に便利 |
| 安全 | 高レベルの敵対パルが集まるエリアを避ける |

> ヒント：序盤は拠点1つ、後期は複数の拠点で役割分担——採掘・伐採・配合を別々に作る方が、単一の「万能拠点」よりもずっと効率的です。

## Palbox と拠点半径

Palbox（パルボックス）は拠点のコアで、2レベルで解放され、15〜30匹のパルを収容できます。**Palbox のカバー範囲が拠点半径**です——これはコミュニティで「拠点が狭い」と言われる根本原因であり、建物を配置する際はまず範囲を確認してください。

- Palbox をアップグレードすると収容数と作業枠を拡張できる
- 拠点のパルが多すぎるとカクつくため、抱えすぎないこと

## 12種の作業適性（Work Suitability）

各パルはレベル0〜4の作業適性を持ち、レベルが高いほど効率が上がります（例：採掘Lv3はLv1の3倍速い）：

| 作業タイプ | 英語 | 説明 |
|-----------|------|------|
| 生火 | Kindling | 溶鉱炉、料理 |
| 水やり | Watering | 農地、給水システム |
| 栽培 | Planting | 農作業 |
| 発電 | Generating Electricity | 電力施設 |
| 手工 | Handiwork | 制作ステーションの高速化 |
| 採取 | Gathering | きの実、小規模資源 |
| 伐採 | Lumbering | 伐採 |
| 採掘 | Mining | 鉱石、石 |
| 製薬 | Medicine Production | 薬品 |
| 冷却 | Cooling | 冷蔵 |
| 運搬 | Transporting | 資材の運搬 |
| 農業 | Farming | 牧場の生産 |

## SAN管理とパルの状態

SAN（Sanity、理性値）の低いパルは作業が遅くなり、病気になり、最終的にストライキを起こします。SANを維持するには3つのことが重要です：

1. **ベッド**：十分な寝床を確保する
2. **食事**： Feed Box（給餌箱）を満たしておく。切らさないこと
3. **温泉 Hot Spring**：パルの理性を回復させる

> ヒント：SANの低下は「パルが働かない」最も一般的な原因です。まずベッド・食事・温泉を確認し、すぐにパルを入れ替えないでください。

## 拠点防衛

定期的に敵対勢力や野生パルが拠点を襲撃します：

- 壁を建て、1〜2か所の隙間（ choke point ）を残して敵を集める
- 隙間に防衛施設（ボールista、機関銃タワー）を配置する
- 戦闘型パルを配置して防衛する

## 効率的なレイアウトのコツ

- **垂直スタッキング**：高く積み上げる方が、横に広げるより省スペース
- **保管を生産の近くに**：倉庫を作業ステーションの隣に置き、パルの運搬時間を減らす
- **専用拠点**：採掘・伐採・配合は別々に建て、混ぜないこと

## 初心者のよくあるミス（コミュニティで多い落とし穴）

1. 作業ステーションを作りすぎたが、労働者が足りない
2. 捕まえたパルに作業を手動で割り当てない（自動では就業しない）
3. 立地の近くに鉱脈がなく、後期に引っ越しを余儀なくされる
4. パルの幸福度をないがしろにする（空腹・ベッドなし・温泉なし）
5. 保管が生産ステーションから遠すぎる

> 上記のどれか3つを正せば、拠点の生産能力は倍増します。
