Palworld の Mod エコシステムは PC (Steam) 版のみに限られます。本ページでは導入方法とおすすめの方向性を紹介します。

## 結論から

- Mod は **PC (Steam) 版のみ**
- PS5 / Xbox / Mac は Mod 非対応
- 公式は Steam ワークショップに対応

## 導入方法

### 方法一：Steam ワークショップ

1. Palworld の Steam ワークショップページを開く
2. Mod を閲覧して購読（サブスクライブ）する
3. ゲームを起動すると、Mod が自動で読み込まれる
4. ゲーム内で購読済みの Mod を管理する

### 方法二：ローカルでの手動導入

1. Mod ファイルをダウンロードする
2. Palworld のゲームディレクトリの Mods フォルダに入れる
3. ゲーム起動時に有効化する

## おすすめの Mod の方向性

> 以下は方向性のおすすめです。具体的な Mod 名はワークショップのその時点の検索結果を正としてください。

| 方向性 | 説明 |
|--------|------|
| 物流効率 | コンベア/運搬パルの効率を最適化 |
| マップ強化 | 資源ポイント/BOSS位置を表示 |
| 自動化補助 | 自動給餌/自動配合補助 |
| UI 改善 | パル管理画面の改善 |
| 画質強化 | 映像の最適化 |
| QoL ツール | クイック操作、一括管理 |

## 互換性に注意

1. **バージョン更新で Mod が効かなくなる可能性**：ゲームの更新後は都度 Mod の互換性を確認する
2. **Mod と EA 版の互換性**：1.0正式版以降、一部の古い Mod は更新が必要になる場合がある
3. **専用サーバーの Mod**：サーバーとクライアントに同じ Mod を導入する必要がある
4. **クロスプレイ**：Mod を使った PC プレイヤーは、Mod 未導入のサーバーに参加できる（Mod による）

## Pal Surgery Table（パル手術台）でのパッシブ変更

1.0 バージョンと Terraria コラボのアップデートで導入された Pal Surgery Table（パル手術台）は、公式内蔵の「パッシブスキル変更」機能です：
- パルのパッシブスキルを上書きできる
- パルの性別を変更できる
- Surgery Chip（手術チップ）が必要

> これは Mod ではなく公式機能で、すべてのプラットフォームで利用できます。
