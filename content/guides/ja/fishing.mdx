釣り Fishing は Palworld が v0.6.0（Tides of Terraria）アップデートで追加したシステムです。本ページでは釣りのすべてのデータをまとめます：技術解放、野外釣りポイントの格付け、釣れるパル78種、拠点の釣り池の捕獲率、引き揚げドロップ表、餌と釣りパル。

## 釣りの前提：技術の解放

すべての釣り竿、餌、釣り池は**技術解放**のみで、ワールドドロップはありません。釣り竿だけでは投げられません——バッグに餌も入っている必要があります。

## 野外釣りポイント：6段階の格付け

各野外釣りポイントには6段階のいずれかが付き、段階は以下を決定します：影の戦闘難度、食いつくパルのレベル幅、および1回の投竿で消費する釣り竿の耐久度。

| 釣りポイントの段階 | 戦闘難度 | 捕獲レベル | 1回の耐久消費 | 池内パル数 |
|---------------------|----------|------------|---------------|------------|
| Beginner（初級） | 15–78 | Lv 1–28 | 1 | 15匹 |
| Intermediate（中級） | 38–87 | Lv 20–45 | 1/2/4 | 30匹 |
| Advanced（上級） | 52–96 | Lv 30–69 | 2/4 | 22匹 |
| Expert（達人） | 52–106 | Lv 40–69 | 4 | 28匹 |
| Master（名人） | 84–106 | Lv 65–69 | 4 | 4匹 |
| Grand Master（宗師） | 104–130 | Lv 71–79 | 4 | 4匹 |

> 最下段階では1耐久で投げられますが、Advanced からは毎回4耐久——同じ釣り竿では最上位で1/4回しか投げられません。深水域へ行く前に予備の釣り竿を持参してください。

## 拠点の釣り池

2種の釣り池（釣り池、大型釣り池）はいずれも**生産建物**で、手工（Handiwork）パルを1匹割り当てる必要があります。建設すると自動で釣りを始め、これが手動で投竿して確率を狙う唯一の方法です。

- 大型釣り池は後期に解放され、家で最大の影の魚を釣れる
- 釣り池には**2人目の労働者を置けない**。枠上限は1匹で、手工レベル1で十分
- **設置制限**：拠点キャンプの半径内にしか建てられず、湖畔には建てられない
- 大型釣り池は作業量 85,000（小池は 23,500）が必要で、ゲーム内で最も重い建物の1つ
- 釣り池は **SAN を消費しない**（牧場、配合農場、油ポンプと同様）。しかし手動操作モードがなく、労働者を割り当てないと何もしない

### 捕獲率（影の大きさ別）

| 影 | 最上位の通常捕獲 |
|----|------------------|
| 小 Small | Killamari / Jelliette / Turtacle / Jellroy / Celaray / Pengullet / Kelpsea / Croajiro / Fuack 各 9.5% |
| 中 Medium | Gloopie 10%、Celaray Lux 9.5%、Surfent / Dumud 各 9.5% |
| 大 Large | Azurobe Cryst 11%、Turtacle Terra 10.1%、Croajiro Noct / Penking Lux / Whalaska / Whalaska Ignis / Ghangler Ignis 各 7.3% |

> Boss サイズ版の捕獲率は通常版よりはるかに低く（多くは0.2%–0.5%）、稀な大当たりです。

### わざわざ狙って釣る3つのもの

1. **釣り竿の設計図**：釣り池は所有しているより1段階上の設計図をドロップすることがある。高級設計図は Azurobe Cryst / Finsider Ignis / Ghangler Ignis / Whalaska の表にのみ出現し、約 **440回の大影捕獲につき1枚**。
2. **古代テクノロジー**：太陽球、古代球、古代文明のコア、古パル手稿は、大影の Skutlass/Solmora の表と Whalaska Ignis の表にのみ出現。小/中影では一切ドロップしない。
3. **サンゴ鉱石 Coralum Ore**：Munchill/Polapup の表の1〜3から始まり、4つの大表で堆積数が増加（2〜4 → 8〜18 → 12〜21 → 18〜27）。Whalaska Ignis の表は全プールで最高の金ロール（7,000〜7,500）もある。

## 引き揚げ Salvage（マグネット釣り）

開けた水域の**浮いた残骸**に向けて投げると食いつかず、代わりにゴミ箱が引っかかります。影もサイズ目標もなく、餌は関与しません。消費するのは**マグネット**で、どのマグネットを持つかでどの表に投じるかが決まります。

| マグネット | コスト |
|------------|--------|
| 通常引き揚げマグネット | 鉄インゴット×1 で10個作成可、技術不要 |
| 強力引き揚げマグネット | 技術 Lv 62、六稜晶×1 ＋ 低温冷却剤×1 ＋ バイオバッテリー×1 で10個作成可 |

### 浅瀬 vs 深瀬（核心の違い）

| | 浅瀬（通常マグネット） | 深瀬（強力マグネット） |
|---|---|---|
| 主な産出 | **金**（1回あたり約1,660） | **ドッグコイン ＋ 設計図 ＋ マニュアル ＋ サンゴ鉱石** |
| 設計図 | 初心者釣り竿設計図 1% | 24種の武器/六稜晶防具の設計図（計12.4%） |
| サンゴ鉱石 | 1〜2（30%の確率） | 6〜11（毎回確定） |
| 訓練マニュアル | M/L 少量 | L/XL 各 21.9% |

> 深瀬の引き揚げは最も速いサンゴ鉱石の入手手段の1つ。浅瀬の引き揚げはゲーム内で最も安定した序盤の金収入の1つです。

## 餌の比較

餌は直線的な強化ではありません——各種が変える数値は異なります。**Sweet Bait と High Quality Bait は仕組みが完全に同じ**です。

| 餌 | 効果 |
|----|------|
| Simple Bait（簡単な餌） | 基準、修正なし |
| High Quality Bait（高品質餌） | 食いつき確率 ×1.5 |
| Deluxe Bait（豪華餌） | 捕獲ゲージ ×1.15 |
| Beginner Bait（初心者餌） | ゲージ減少 ×0.68 |
| Sweet Bait（甘い餌） | 食いつき確率 ×1.5（高品質と同じ） |
| Lucky Bait（幸運の餌） | 捕獲ゲージ ×1.25、アイテムとパルのドロップ ＋40% |
| Quick Bait（早い餌） | 食いつき確率 ×1.5、捕獲ゲージ ×1.25 |
| Alluring Bait（魅惑の餌） | 捕獲ゲージ ×1.3、アイテムとパルのドロップ ＋40% |
| Risky Bait（冒険の餌） | 捕獲ゲージ ×1.3、アイテムとパルのドロップ ＋80%（ゲージが狭くなる） |

> 素材を釣らずパルを釣る → **Risky Bait**（二重ドロップロールを倍にできる唯一の餌）。ただ攻略したいだけ → **Alluring Bait**（最も広いゲージ）。

## 釣りパル7匹（パートナースキル）

7匹のパルにはパートナースキルが**水辺でのみ発動**します（数値幅は rank 1 → 5）。これらのスキルは何が釣れるかを変えるのではなく、釣り上げに成功するかどうかを決めます。

| パル | スキル | 効果 |
|------|--------|------|
| Jelliette | Jelliette Drop | 付随アイテム ＋55% → ＋95% |
| Jellroy | Jellroy Drop | 引き揚げ収穫 ＋55% → ＋95% |
| Solmora Lux | Shocking Fish | 高ポテンシャルパルの確率 ＋74% → ＋82% |
| Solmora | Charming Fish | 高ポテンシャルパルの確率 ＋70% → ＋80% |
| Gloopie | Sticky Princess | ゲージが外れた際の減少 －12% → －35% |
| Whalaska Ignis | Cozy Whale Cruiser | 開始時ゲージ一部充填 ＋7% → ＋17%；照準充填 ＋7% → ＋17% |
| Whalaska | Chilled Whale Cruiser | 開始時ゲージ一部充填 ＋5% → ＋14%；照準充填 ＋5% → ＋14% |

### 用途別の選び方

- **高品質パルを残したい** → Solmora Lux（74→82% ポテンシャル加算、釣り物の質を変える唯一のスキル）
- **素材を釣る** → Jelliette（満レベルでアイテムとパルのドロップ各 ＋95%、Risky Bait と組めばさらに倍増）
- **残骸を引き揚げる** → Jellroy（加算は引き揚げのみに作用）
- **ミニゲームが辛い** → Whalaska Ignis（Whalaska を厳密に上回る）；Gloopie の 12→35% 減少カットは最大の単項数値で最も早く入手できる

> Solmora と Solmora Lux のみが水面マウント。星の引き上げは濃縮（同種の重複が必要）または星の実（メダルショップのドッグコインと交換）による。

## 釣りのコツ

1. **水中の影を観察**：大影 ＝ 大きな魚/希少パル、Boss サイズは稀な大当たり
2. **予備の釣り竿を持参**：高レベルの釣りポイントでは1回の投竿で4耐久消費
3. **釣り池を空にする**：釣り池は捕獲したパルを取り出さない限り新しい目標を受け付けず、パルボックスが満杯だと停止する
4. **釣りパルを組み合わせる**：Jelliette で素材、Solmora Lux で品質、Jellroy で引き揚げ
