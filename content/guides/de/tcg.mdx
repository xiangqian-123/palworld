## Kartentypen

Das Palworld TCG hat 5 Kartentypen:

| Typ | Beschreibung |
|------|------|
| Pals | Kern-Kampfeinheit, hat Angriff und Ausdauer |
| Gears (Ausrüstung) | An Pal ausrüsten, verstärkt Fähigkeiten |
| Structures (Gebäude) | In die Basis-Zone platzieren, bieten Funktion |
| Events | Sofort-Effekt-Karten |
| Souls (Seelen) | Ressource zum Ausspielen von Pal/Ausrüstung/Gebäude |

## Spielweise im Überblick

- Deck: 50 Karten
- Ziel: Den Life Counter des Gegners von 10 auf 0 senken
- Pro Runde 2 Souls ziehen (Limit 10)
- Souls nutzen, um Karten in die Base-Zone auszuspielen
- Pal kann gegnerische Pals / Gebäude angreifen oder direkt den Spieler Strike treffen
- Der Power-Wert entscheidet den Kampf, HP wird jede Runde zurückgesetzt
- Die Strike-Anzahl bestimmt die Anzahl umgedrehter Karten, Lucky Symbol kann Schaden abwehren
