Das Palworld-Mod-Ökosystem ist nur für die PC-Version (Steam) verfügbar. Diese Seite stellt Installationsmethoden und Empfehlungsrichtungen vor.

## Fazit vorab

- Mods **nur für PC-Version (Steam)**
- PS5 / Xbox / Mac unterstützen keine Mods
- Offizieller Steam Workshop wird unterstützt

## Installationsmethoden

### Methode 1: Steam Workshop

1. Öffne die Steam-Workshop-Seite von Palworld
2. Durchsuche und abonniere Mods
3. Starte das Spiel, Mods werden automatisch geladen
4. Verwalte abonnierte Mods im Spiel

### Methode 2: Lokale manuelle Installation

1. Lade Mod-Dateien herunter
2. Lege sie in den Mods-Ordner des Palworld-Spielverzeichnisses
3. Beim Spielstart aktivieren

## Empfohlene Mod-Richtungen

> Folgende Richtungsempfehlungen; konkrete Mod-Namen über die Live-Suche im Workshop.

| Richtung | Beschreibung |
|----------|--------------|
| Logistik-Effizienz | Optimiert Förderband/Transport-Pal-Effizienz |
| Kartenverbesserung | Zeigt Ressourcenpunkte/BOSS-Positionen |
| Automatisierungshilfe | Automatisches Füttern/Züchten-Hilfe |
| UI-Verbesserung | Verbessert Pal-Verwaltungsoberfläche |
| Grafikverbesserung | Bildoptimierung |
| QoL-Werkzeuge | Schnellaktionen, Massenverwaltung |

## Kompatibilitätshinweise

1. **Versionsupdate kann Mods unbrauchbar machen**: Nach jedem Spielupdate Mod-Kompatibilität prüfen
2. **Mods mit EA-Version kompatibel**: Nach 1.0-Version brauchen einige alte Mods ein Update
3. **Dedicated-Server-Mod**: Server und Client müssen dieselben Mods installiert haben
4. **Cross-Play-Multiplayer**: PC-Spieler mit Mods können Servern ohne Mods beitreten (je nach Mod)

## Pal Surgery Table (Passiv ändern)

Die mit der 1.0-Version und dem Terraria-Crossover eingeführte Pal Surgery Table (Pal-Operationstisch) ist eine offiziell eingebaute Funktion zum „Ändern von Passiv-Fähigkeiten":

- Kann Passiv-Fähigkeiten eines Pals überschreiben
- Kann das Geschlecht eines Pals ändern
- Benötigt Surgery Chip (Operations-Chip)

> Das ist keine Mod, sondern eine offizielle Funktion, auf allen Plattformen verfügbar.
