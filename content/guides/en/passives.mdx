Each Pal can have up to 4 passive skills, granting bonuses or negative effects to attack, defense, work speed, move speed, sanity and more. The game has **115 passives total: 100 positive + 15 negative**, of which **40 can be directly granted via Pal Surgery**. Rarity ranges from **Rank 5 (World Tree set, strongest) to Rank -3 (worst)**.

> Data based on 1.0 game files, updated July 2026.

## How Passives Work

1. **Four slots**: Wild Pals and hatched eggs can get up to 4 random passive skills; empty slots stay until filled via breeding or surgery.
2. **Breeding is the main source**: Offspring randomly inherit passives from both parents; over generations you can stack target passives onto one Pal.
3. **Surgery override**: Passives marked 🔪 can be directly applied via Pal Surgery, no re-breeding needed — including Rank 5 World Tree set and most Rank 4 passives.

## Key Passive Effect Notes (easy to get wrong)

| Passive | Correct Effect | Common Misconception |
|------|---------|---------|
| Serenity | Active skill cooldown -30% + attack +10% | ❌ Mistaken as "SAN recovery" |
| Philanthropist | Boosts **breeding speed** (breeding timer) | ❌ Mistaken as "ranch egg production" |
| Remarkable Craftsmanship | +75% work speed (rainbow tier) | ❌ Mistaken as "Golden Touch" (doesn't exist) |
| Siren of the Void | +30% Dark + 30% Ice | ❌ Mistaken as "Shadow Ruler" (doesn't exist) |

### Pure DPS Combat
```
Legend + Musclehead + Serenity + 30% elemental passive
```

### Elemental DPS Combat
```

```

### Tank / Survivability
```
Legend + Diamond Body + Burly Body + Stronghold Strategist
```

### Speed Mount
```
Swift + Runner + Legend + Infinite Stamina/Nimble
```

### Ultimate Base Worker
```
Artisan + Work Slave + Serious + Remarkable Craftsmanship
```
> Work speed: base 70 × 215% (passives) × 130% (boost) = ~195. After 4-star condensation, each work suitability +1; each level is 3× faster than the previous (Lv1→Lv5 ≈ 81×).

## Passive Inheritance Rules

1. After merging both parents' passives (dedupe), roll "inheritance count" (1–4, probability 40%/30%/20%/10%)
2. **Identical passives on both parents neither help nor hurt**
3. Probability of inheriting all target passives: 1 → 40%, 2 → 24%, 3 → 12%, 4 → 10%
4. Best practice: parents total only 4 target passives (2+2 / 3+1 / 4+0)
5. **Legend, elemental Emperors cannot mutate randomly**, must be inherited from parents

See [Breeding Guide](/en/guide/breeding).

## Pal Surgery Table Modify Passives

The Pal Surgery Table introduced in v0.6.0 can:
- Override existing passives (costs gold; some passives need implants)
- Change Pal gender
- Key passives like Serious / Nocturnal / Philanthropist / Workaholic can be directly implanted (no implant needed first)

> Available on all platforms (not just PC); it's an official built-in feature.
