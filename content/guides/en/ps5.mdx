Palworld is available on PlayStation 5. This page covers PS5 purchase, multiplayer and notes.

## Conclusion First

- PS5 **has** Palworld, purchased on PlayStation Store for $29.99
- PS4 **does not have** Palworld, no PS4 version
- PS5 supports **cross-platform multiplayer** (with PC, Xbox, Mac)
- PS5 dedicated servers launched after the v0.6.0 (Tides of Terraria) update

## How to Buy

Search Palworld on PlayStation Store to purchase and download. Supports PS5 console, not backward compatible with PS4.

## Cross-Platform Multiplayer

PS5 players can play with these platforms:

| Platform | Multiplayer |
|------|------|
| PC (Steam) | Supported |
| Xbox Series X|S / One | Supported |
| Mac | Supported |
| Nintendo Switch | Not supported |

The host enables Cross-Play in World Settings → then shares the invite code.

## PS5 vs Steam Version

| Item | PS5 | Steam |
|------|-----|------|
| Mod support | Not supported | Supported |
| Dedicated server | Supported (since v0.6) | Supported |
| Cross-platform | Supported | Supported |
| Controller experience | DualSense haptic feedback | Needs external controller |
| Cloud save | PlayStation cloud save | Steam cloud save |
| Cross-save | No cross-save | No cross-save |

> Note: Palworld **does not support cross-save**. Saves are tied to the platform they were created on; the Global Palbox can only transfer Pals between the same platform under the same account.

## PS5 FAQ

### Q: Can PS4 play?
No. Palworld has no PS4 version; PS4 players cannot install or join servers.

### Q: Does the PS5 version go on sale?
Occasionally discounted during PlayStation Store promotions; watch the store page.

### Q: Is PS5 content the same as PC?
The 1.0 full release content is completely identical. Differences are only in mods and control scheme.
