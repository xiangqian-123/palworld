Palworld has been updated continuously since its Early Access launch on January 19, 2024. The full 1.0 version released on July 10, 2026, leaving the EA phase. This page collects the complete version history.

## 1.0 Full Release Core Content

1.0 is the biggest update Palworld has had:

| Content | Description |
|------|------|
| Total Pals | **288 Pals** in the whole game (official wiki data) |
| World Tree | Main-story finale, finally enterable (8-tower sealing arc) |
| Pal Awakening/Mutation | Empower Pals or breed mutant individuals (variant eggs) |
| 200+ Partner Skills reworked | Partner Skills greatly improved |
| New materials | Hardwood, Soralite, Paloxite, World Tree Holy Water, etc. |
| Level cap 80 | Raised from EA phase |
| Multiplayer improvements | Cross-platform multiplayer, voice chat, guild permissions, server tools |

## Major Update Details

### v0.5.0 — Cross-Platform Multiplayer (2025-03-19)
First supported cross-platform multiplayer across PC / PS5 / Xbox / Mac. The host enables Cross-Play in World Settings.

### v0.6.0 — Tides of Terraria (2025-06-25)
Terraria crossover: added 27 Pals, 3 islands, Terraria dungeon, fishing/salvage systems, Arena. See [Terraria Crossover Guide](/en/guide/terraria).

### 1.0.0 — Full Release (2026-07-10)
The biggest update. Announced at Summer Game Fest 2026. Opened the World Tree main-story finale, Pal awakening/mutation systems, and a total of 288 Pals. Steam 25% off for celebration.

## Nintendo Patent Dispute

The lawsuit between Palworld and Nintendo (and The Pokémon Company) is one of the biggest gaming controversies in recent years. Full timeline:

| Time | Event |
|------|------|
| 2024-01-24 | The Pokémon Company issued a statement saying it had received many inquiries about "a game launched by another company in January" and would "investigate and take appropriate measures" |
| 2024-09-18 | **Nintendo + The Pokémon Company formally sued Pocketpair in the Tokyo District Court**, alleging patent infringement (Pal Sphere capture mechanic similar to Pokémon's capture mechanic) |
| 2024-09 | Claim amount: **5 million yen each** + delay damages, and seeking an injunction to block Palworld's release |
| 2024-11 | Pocketpair responded "unaware of infringing any patent" and released a patch modifying the Pokémon-like mechanic |
| 2024-12 | Nintendo filed 23 patents in the US, ultimately **1 approved, the rest rejected** |
| 2025 | Pocketpair argued: precedents like the Dark Souls III Pocket Souls Mod make Nintendo's patents invalid; Nintendo said "Mods don't count as standalone games and don't constitute patent infringement" |
| 2026-10-01 | Court scheduled **evidence presentation** |
| 2026-11-09 | Court will **issue opinion** |

> Due to the lawsuit, a Palworld Nintendo Switch release is highly unlikely; there is also no PS4 version yet.
