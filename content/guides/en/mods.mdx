Palworld's mod ecosystem is limited to the PC (Steam) version. This page covers installation methods and recommended directions.

## Conclusion First

- Mods **limited to PC (Steam) version only**
- PS5 / Xbox / Mac don't support mods
- Officially supports Steam Workshop

## Installation Methods

### Method 1: Steam Workshop

1. Open Palworld's Steam Workshop page
2. Browse and subscribe to a mod
3. Launch the game; the mod loads automatically
4. Manage subscribed mods in-game

### Method 2: Local Manual Install

1. Download the mod files
2. Place them in the Mods folder of the Palworld game directory
3. Enable them at game launch

## Recommended Mod Directions

> The following are directional recommendations; specific mod names depend on live Workshop search.

| Direction | Description |
|------|------|
| Logistics Efficiency | Optimize conveyor belts / transport Pal efficiency |
| Map Enhancement | Show resource points / BOSS locations |
| Automation Aids | Auto-feed / auto-breeding helpers |
| UI Improvements | Improve Pal management interface |
| Visual Enhancement | Graphics optimization |
| QoL Tools | Quick actions, batch management |

## Compatibility Notes

1. **Version updates may break mods**: Check mod compatibility after each game update
2. **Mods vs EA version**: After 1.0 some old mods may need updates
3. **Dedicated server mods**: Server and client need the same mods installed
4. **Cross-platform multiplayer**: PC players using mods can join unmodded servers (depends on the specific mod)

## Pal Surgery Table Modify Passives

The Pal Surgery Table introduced in 1.0 and the Terraria crossover update is an official built-in "passive skill modification" feature:
- Can override a Pal's passive skills
- Can change a Pal's gender
- Requires a Surgery Chip

> This is not a mod — it's an official feature available on all platforms.
