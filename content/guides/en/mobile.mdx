Palworld currently has no native mobile version. This page explains the current status and alternatives.

## Conclusion First

- iOS/Android **no native Palworld main-game version yet**
- **Palworld Mobile**: Mobile version developed by Krafton, planned for 2026 release
- **Palworld Online**: Mobile MMORPG developed by Garena, planned for 2026 release
- Both projects above are **standalone games**, not a port of the main game

## Alternative: Cloud Gaming Streaming

Although there's no native mobile version, you can play on mobile via cloud gaming:

| Option | Requirement | Latency |
|------|------|------|
| Xbox Game Pass Ultimate Cloud Gaming | Game Pass Ultimate subscription | Low (official cloud service) |
| Steam Link Streaming | PC running Steam + same network | Medium (depends on network) |
| GeForce NOW | NVIDIA subscription | Low |

## Krafton Palworld Mobile

A standalone mobile Palworld developed by Pocketpair in partnership with Krafton (PUBG developer). So far only "releasing in 2026" is confirmed; specific gameplay and launch date to be announced. This is not a port of the main game, but a standalone mobile experience.

## Garena Palworld Online

A mobile MMORPG developed by Garena under license from Pocketpair, called Palworld Online. Also a standalone project with an original story and a shared open world. Expected 2026, no specific date or cross-save info yet.

## Why EA Games Usually Launch on PC First

Open-world survival games demand high hardware performance (physics simulation, AI computation, large map rendering); mobile needs major optimization or even redesign. Pocketpair chose to finish the PC/console 1.0 first, then push mobile projects in parallel.
