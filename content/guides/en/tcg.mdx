## Card Types

Palworld TCG has 5 card types:

| Type | Description |
|------|------|
| Pals | Core combat units, with attack and stamina |
| Gears | Equip to Pals to boost abilities |
| Structures | Placed in the base area, provide functions |
| Events | Instant-effect cards |
| Souls | Resource to deploy Pals/Gears/Structures |

## Gameplay Overview

- Deck: 50 cards
- Goal: Reduce opponent's Life Counter from 10 to 0
- Draw 2 Souls each turn (max 10)
- Use Souls to deploy cards to the Base area
- Pals can attack opponent Pals / structures / or directly Strike the player
- Power value decides combat; HP resets each turn
- Strike count decides cards flipped; Lucky Symbol can negate damage
